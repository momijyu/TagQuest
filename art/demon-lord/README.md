# 魔王

正本は `web/src/data/characters/demon-lord.ts`。整数ピクセルを直接描いた16色の素材です。
金の角兜、黒紫の鎧、赤いマント、銀髪、赤い目と長剣を共通のデザインにしています。

- `standing.png`：フィールド用、32×32px。配置枠は横1×縦2マス、当たり判定は下側1×1マス。
- `battle.png`：戦闘用、64×56px。戦闘画面では補間なしの2倍で描画します。
- `preview.png`：左＝立ち姿、右＝戦闘用の4倍の見本。

紹介画面の「宝箱・魔女・妖精・魔王」と「モンスター」で確認できます。
エディタのNPCから「魔王」を置き、会話はテンプレートID 9または自由文で指定します。
歩行中の確率戦闘はステージの「エンカウント」から敵ID 4を指定します。NPCの「話しかけて戦闘」に敵ID 4を指定すると、会話の後に戦闘へ移ります。
素材・配置ID 31・敵ID 4は別の役割を持ち、既存のIDは変更していません。

HP360・攻撃36・防御12、剣と闇の炎の攻撃、報酬0G・0EXP・アイテムなしは動作確認用の仮設定です。
`web/src/data/encounters/enemies/demon-lord.json` から編集できます。
遭遇場所と確率はNFCに保存するステージ設定で指定します。魔王城の見本は玉座前 `(128,64)` pxに魔王NPCを置き、`battleEvent: { enemyId: 4, once: true, clear: true }` を設定しています。会話から戦闘に移り、勝利で消失してGAME CLEAR、逃走・敗北は再戦できます。確率エンカウントで魔王を指定した場合は再遭遇します。

`web/` で `npm run export:demon-lord` を実行するとPNGを再出力できます。
共通のNPC一覧は `export:adventure-materials`、敵の一覧は `export:enemy-pixels` で再出力します。

# 通常の世界：16マップの冒険見本

紹介画面の「歩いてみる」→「通常の世界」で、城・街・全体マップ・森・洞窟・魔王城を行き来できます。
エディタの「＋ 通常の世界（16マップ）」は16マップをまとめて追加し、空いているIDへ出口の参照も割り当て直します。
既存の編集内容は変更せず、「戻す」で追加だけ取り消せます。
以前の充実したデモを通常版として維持し、別に [巨大版](../adventure-large/README.md) と [NFC小型版](../adventure-small/README.md) を用意しました。

## 編集する正本

- 充実版の城：`compiler/maps/adventure-castle.json`。
- 広場型の街：`compiler/maps/adventure-town.json`。
- 森の地形・木・池・キラキラ：`compiler/maps/forest.json`。
- 魔王城の地形・柱・玉座・魔王戦：`compiler/maps/demon-castle.json`。
- 洞窟の地形・岩壁：`compiler/maps/cave.json`。
- 全体マップ：`compiler/maps/world.json`。
- 新しい8本の出口：`compiler/maps/adventure-connections.json`。
- 見本専用のNPC・宝箱・会話／アイテム設定：`compiler/maps/adventure-content.json`。
- 森・洞窟の見本専用出現表：`compiler/maps/adventure-encounters.json`。
- 接続したワールドの組み立て：`web/src/editor/adventure.ts`。

接続した見本は専用の城・街に出口と探索内容を追加します。NFC用の標準城・街は別に保持します。森・洞窟では最後の行の地面を空白にし、魔王城では下端の両脇を空白にして、出口だけを1マス突き出します。
原寸マップIDは城0・街1・全体マップ2・森3・洞窟4・魔王城5。出口座標は0始まりで、到着座標は主人公の足元を指定します。

| 接続 | 出口 | 到着 | 向き |
|---|---|---|---|
| 城 → 街 | (6,11) | (12,7) | 下 |
| 街 → 城 | (12,6) | (6,9) | 上 |
| 全体マップ → 街 | (8,15) | (12,19) | 上 |
| 街 → 全体マップ | (12,20) | (8,16) | 下 |
| 全体マップ → 森 | (7,13) | (9,15) | 上 |
| 森 → 全体マップ | (9,16) | (7,14) | 下 |
| 全体マップ → 洞窟 | (12,12) | (9,15) | 上 |
| 洞窟 → 全体マップ | (9,16) | (12,13) | 下 |
| 全体マップ → 魔王城 | (23,4) | (8,17) | 上 |
| 魔王城 → 全体マップ | (8,18) | (23,5) | 下 |

場所の外観に透明な1×1の出口を重ねます。帰りは入口の隣へ着くので、到着直後に行ったり来たりしません。
街と城も新しい入口・出口座標で接続します。森・洞窟には3種類ずつのランダムエンカウントを設定しています。魔王城は魔王NPCに話しかける戦闘を設定済みです。

## 森

19×17マス。既存の森の地面・草・土・海の水面・48×48の木を使い、曲がった道と広場、池を置いています。
木は幹の足元1×1マスだけが通行不可。広場にやくそう（ID 0）のキラキラが1個あり、再訪でも取得済み状態を維持します。
充実版の森はリーフジェル・おばけキノコ・森オオカミを6%で抽選します（比率5:3:2）。単体の森テンプレートは未設定です。モンスター素材とステータスはWeb側に保管し、敵IDと出現率はNFCに保存するステージ設定で指定します。エディタのエンカウント欄から設定すると、バイナリに保存されます。
妖精から森の様子を聞けます。宝箱は木の盾（ID 7）・まほうの水（ID 2）に加え、寄り道の上やくそう（ID 19）とどくけし丸（ID 20）。西の木陰と東の小さな広場へ土の枝道をつなぎ、道しるべを置きました。充実版の見本画像は [forest.png](./forest.png)。

## 洞窟

19×17マス。16×16ドットの岩の床と壁を使い、入口から曲がった道で左右の広間へ進みます。洞窟の魔女は奪われた灯火と守護者の過去を語り、宝箱には革の鎧（ID 6）・銅の剣（ID 4）・どくけしそう（ID 1）に加え、左右の新しい横穴にはまほうの水（ID 2）と力のお守り（ID 8）があります。水晶と道しるべを置き、中央の通路へ戻れます。洞窟コウモリ・岩ヤドカリ・水晶トカゲを8%で抽選します（比率5:3:2）。単体テンプレートは未設定です。下端 `(9,16)` から全体マップへ戻ります。[洞窟の素材と編集方法](../cave/README.md) を参照してください。

洞窟の見本画像は [cave.png](./cave.png)。

## 魔王城

17×19マス。暗い石床と壁、紫のカーペット、6本の柱と玉座を配置した広間です。玉座は中央の横1マスだけをふさぎ、正面から調べられます。玉座前 `(128,64)` pxに魔王NPCを配置しています。敵ID 4の戦闘に勝つと魔王が消えてGAME CLEARとなります。現在の魔王は逃走不可で、敗北なら再戦できます。クリア後はお祝い表示を残し、歩行・帰還・会話を続けられます。下端 `(8,18)` から全体マップへ戻ります。[素材と編集方法](../demon-castle/README.md) を参照してください。

魔王城には案内役と、やくそう・まほうの水の宝箱も配置しています。会話・開戦表示で魔王の攻略ヒントは出しません。[demon-castle.png](./demon-castle.png) で全景を確認できます。

## 城と街の寄り道

城内は7×6から13×12マスへ広げ、中央の赤いカーペットと4本の柱、左の宝箱区画を配置。街は13×31から29×21マスへ広げ、中央の広場と通路を空け、3軒の店・4軒の家・井戸を周囲へ配置しました。住民は草地へ、宝箱は主要通路の脇へ移し、会話・取得のために隣まで歩けることを検証します。下端は地形・壁を含めて出口1マスだけが突き出す形です。

城にやくそうの宝箱、街に井戸のまほうの水と民家の力のお守りを追加。住民から街や回復魔法の話を聞けます。城の隠し王様との遭遇率は1歩ごと0.01%です。武器屋・防具屋・道具屋とキラキラは既存のものを使います。[castle.png](./castle.png)、[town.png](./town.png)、[world.png](./world.png)。

宝箱は計12個。井戸・民家を含めた一度きりの調査報酬は15件で、既存のキラキラ3件も残しています。取得済みの宝箱は空になり、ステージを往復しても取得状態を保持します。会話は17件すべて定型文IDで指定します。

## 出力

`web/` で `npm run export:adventure` を実行すると、このディレクトリへワールドJSON・TQ v15バイナリ・容量レポート・公開先URLと16枚のPNGを再出力します。
`world.json` をエディタの「JSONを開く」で読み込めます。この操作は編集全体を置き換えるので、追加だけなら上記の見本ボタンを使います。

16マップ合計1,463B。公開先 `https://tag-quest-kappa.vercel.app/` でURL1,987B、NDEF/TLV1,992Bとなります。容量の正本は `world.report.json`。ブラウザ試遊・URL共有向けの見本です。
この通常版は探索内容を優先します。NTAG215向けの6マップ版は [adventure-small](../adventure-small/README.md) に302B・URL439B・NDEF444Bで保管します。従来の城＋街だけのcompact見本も199B・NDEF307Bで [art/nfc](../nfc/README.md) に残します。通常版をNTAG215へ書き込むことはできません。

森・洞窟の戦闘で成長し、宝箱や店の装備・回復品を使って魔王を倒すとクリアです。王様は0.01%の隠し遭遇で、撃破はクリアの必須条件にしません。隠し装備と魔王の攻略ヒントはゲーム内会話に出しません。

## 物語と敗北

「消えた灯火」を取り戻すため、南の王から旅立ち、街の住民・森の妖精・洞窟の魔女を訪ねて魔王城へ向かいます。魔王が灯火を閉じ込めた理由と、失った故郷の記憶を会話でたどれます。「つよさ」に次の目的が出ます。会話は必須通行条件にはせず、魔王撃破後には結末と後日談を表示します。本文はWeb側の [会話テンプレート](../../web/src/data/dialogue-templates.json)、目的・結末は [adventure-story.json](../../web/src/data/adventure-story.json) で編集します。

敗北では所持金が半分（残額切り捨て）になり、復活時に損失を表示します。装備・道具・経験値・取得済み状態は維持し、HP・MP全快、毒解除で再開します。巨大版には第2の城と会話専用の北の王がいます。


東の住宅通りの新しい赤い家には旅の絵と札、青い家には上やくそうのおすそ分けを置いています。新規会話はID72〜75。共通の既存テンプレートや小型版のデータは変更せず、店舗・出口・会話・宝箱へ歩いて到達できることを検証します。

宿屋の主人・街の出口案内・洞窟のはぐれクリスタルを追加しました。森と洞窟の宝箱は近くの店の商品と区別し、素材装備を入れています。クリア後の裂け目と虚無の異空間はWeb側で追加し、ワールドbinへ含めません。

## 危険地域の拡張（2026-10-14）

湿原・霊峰・火山と、それぞれの巣窟を追加しました。ID6〜11が追加分で、本編の接続と宝箱の数は維持します。近郊の草原にはLv1〜5の敵、危険地域には推奨Lv15〜22／25〜35／35〜45の敵を配置し、入口の看板と画面に警告を表示します。

街の民家3軒を宿屋・酒場・教会へ改装し、NPCの宿泊・賞金首報告・毒治療を実装しました。湿原の魔女の小屋で新しい素材を強化薬や霊薬に交換できます。主ID15〜17は各世界で一度きりの勝負・報酬・消失、ギルドで追加報酬と称号を一度だけ受け取れます。進行と報告は自動保存し、称号・所持品は別世界へ引き継ぎます。

追加の正本は [danger-regions.json](../../compiler/maps/danger-regions.json)、組み立ては [world-expansion.ts](../../web/src/editor/world-expansion.ts)。既存の基本マップと分離して、通常・巨大版だけに呼び出します。小型版の元データとバイナリは変更しません。新しい地形はランダム生成ではなく固定配置です。

全景： [湿原](./poison-marsh.png)、[蜘蛛の毒巣](./arachne-nest.png)、[霊峰](./frost-peak.png)、[氷狼の洞穴](./fenrir-nest.png)、[火山](./burning-battlefield.png)、[紅蓮の竜穴](./volkex-nest.png)。

## 港の商人街・地下水路・沈没神殿

通常版と巨大版にのみ4マップを追加しました。街の東の出口 `(28,12)` から港の商人街へ入ります。鍛冶屋・祠・遊技場・占い・牧場・港の船長・古井戸を利用できます。地下の闇市の合鍵で、鉄格子と古い民家の地下蔵へ入れます。新しい主は追加せず、前回の3体を維持しています。

現在は16マップ・5,515マス、1,463Bバイナリ・URL1,987B・NDEF1,992Bです。小型版の全ファイルは変更しません。`npm --prefix web run export:expanded` は小型版を除いて再生成します。

全景： [旅人の港](./traveler-port.png)、[地下水路と闇市](./black-market.png)、[沈没神殿](./sunken-temple.png)、[合鍵の地下蔵](./locked-house.png)。[操作と編集方法](../../docs/world-facilities-2026-10-14.md) を参照してください。

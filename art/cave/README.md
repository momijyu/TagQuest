# 洞窟の床・壁とマップ

岩の床と壁は `web/src/data/tiles/cave.ts` の16×16のパレット＋ピクセル配列です。PNGはコードから出力した確認用で、ゲームは同じ配列を描画します。

- `floor.png`：灰褐色の岩床。歩けます。
- `wall.png`：明るい上面と暗い割れ目を持つ岩壁。歩けません。
- `stage.png`：19×17マスの洞窟を2倍で表示した見本。

配置の正本は `compiler/maps/cave.json`。下の入口から曲がった通路を進むと左右の広間へ到達できます。壁と床の境目にはWeb側で影を描き、影の部分も床の1マスとして歩けます。

紹介画面の「洞窟」で素材と全景、「歩いてみる」の「洞窟」で試遊できます。全体マップからも洞窟へ入れます。エディタでは「床・壁」の「岩の床」「岩の壁」で編集でき、「＋ 接続した冒険の見本」で城・街・全体マップ・森・洞窟・魔王城を追加できます。以前のブラウザ保存は自動で書き換えません。

## 接続とモンスター

`compiler/maps/adventure-connections.json` に透明な出口を保存します。座標は0始まり、到着位置は主人公の足元です。

| 接続 | 出口 | 到着 | 向き |
|---|---|---|---|
| 全体マップ → 洞窟 | (12,12) | (9,15) | 上 |
| 洞窟 → 全体マップ | (9,16) | (12,13) | 下 |

出現モンスターは未指定です。Web側に素材・ステータス・行動パターンを保管し、敵IDと出現率はNFCに保存するステージ設定から指定します。

## 再出力と保存形式

`web/` で `npm run export:cave-pixels` を実行するとPNGを再出力できます。`npm run export:adventure` は6マップのJSON・バイナリ・容量レポート・仮URLを `art/adventure/` へ出力します。

床カタログの末尾にID 16＝岩床、17＝岩壁を追加しました。TQ v9では洞窟の床ID表 `[2,16,17]` の3Bと、従来の4bitの床圧縮を使います。1マップの床指定は16種類まで。床カタログ全体は256種類まで扱えます。以前の床のみのワールドはTQ v8のままで、旧バイナリも読み込めます。

接続した洞窟は48B（床29B・ヘッダー9B・会話／取得設定2B・出口7B・エンカウント未設定1B）。6マップ合計970Bで、NFCの300B目標への調整と実機読み書きは未完了です。

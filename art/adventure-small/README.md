# NFC用の小さな世界：6マップの冒険見本

城・街・全体マップ・森・洞窟・魔王城をつないだ、NTAG215用の固定ワールドです。通常版から作り直した710マスの箱庭で、地形・配置・会話・宝箱・出現表・出口をデータへ保存します。

紹介画面の「歩いてみる」→「NFC用の小さな世界」から遊び、「この世界の起動URL」でプレイ専用画面を開けます。エディタでは「＋ NFC用の小さな世界（6マップ）」で追加します。既存データもタグ容量に含まれるため、この見本だけを作るなら「全マップを削除」で確認してから追加してください。未編集の初期空マップを置き換え、6枚だけになります。「戻す」で復元できます。[world.json](./world.json) の読み込みでも編集全体を置き換えられます。

| ID | マップ | 大きさ | 内容 |
|---|---|---|---|
| 0 | 小さな城 | 7×7 | 王様、玉座、街への出口 |
| 1 | 小さな街 | 17×11 | 武器・防具・道具の3店、素材交換、民家 |
| 2 | 小さな世界 | 16×16 | 海、砂浜、草地、山、4つの入口 |
| 3 | 小さな森 | 9×9 | 妖精、木、木の盾の宝箱、通常敵3種 |
| 4 | 小さな洞窟 | 9×9 | 魔女、銅の剣の宝箱、通常敵3種 |
| 5 | 小さな魔王城 | 7×8 | 玉座、魔王、勝利でGAME CLEAR |

城→街→全体マップから各場所へ入り、帰還できます。境界の出口は1マス突き出す床で示します。会話はテンプレートID、敵・道具・装備の能力と素材交換はWeb共通configを使います。王様は0.1%の隠し遭遇。森の敵ID 1〜3は12%、洞窟の5〜7は14%（比率5:3:2）。王様の撃破をクリア条件にしません。

現公開先 `https://tag-quest-kappa.vercel.app/` の容量は次のとおりです。

| 内容 | 計算値 |
|---|---:|
| TQ v15 compactバイナリ | 334B |
| Base64urlハッシュ | 446文字 |
| 公開URL全体 | 482B |
| 単一NDEF URI・TLV・終端込み | 487B |
| 追加予約5B込み | 492B / 496B |
| 予約後の残り | 4B |

バイナリの目標300Bは超えますが、現公開先ならNTAG215の標準NDEF領域496Bに計算上収まります。ドメインを長くしたり、自由文・配置・追加レコードを増やす場合は、エディタで容量を再確認します。NFC実機への書き込みは未確認です。

正本は [adventure-small.json](../../compiler/maps/adventure-small.json)。`web/` で `npm run export:adventure -- small`、または `npm run export:demos` で、JSON・バイナリ・容量レポート・URL・6枚のPNGを再生成します。容量の正本は [world.report.json](./world.report.json)、起動URLは [world.url.txt](./world.url.txt)、全景は [world.png](./world.png) と [town.png](./town.png) を参照してください。

`verify:demos` はPython/Webの一致とURL復元、全マップへの実移動、宝箱取得、魔王戦からクリア・帰還・初期化、予約込み容量を検証します。従来の城＋街だけの199B見本は [art/nfc](../nfc/README.md) に別で残します。

小型版でも「消えた灯火」の会話と結末を持ちます。森の妖精と洞窟の魔女を訪ね、魔王城へ向かいます。画面上部と「つよさ」で次の目的を確認でき、クリア後には後日談が変わります。本文はWeb側のテンプレートに保管し、NFCに長文を保存しません。敗北ではG半減、所持品・経験値は保持して復活します。

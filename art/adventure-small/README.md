# NFC用の小さな世界：6マップの冒険見本

城・街・全体マップ・森・洞窟・魔王城をつないだ、NTAG215用の固定ワールドです。通常版から作り直した710マスの箱庭で、地形・配置・会話・宝箱・出現表・出口をデータへ保存します。

紹介画面の「歩いてみる」→「小さな世界」から遊び、「この世界の起動URL」でプレイ専用画面を開けます。エディタでは「＋ 小さな世界（6マップ）」で追加します。既存データもタグ容量に含まれるため、この見本だけを作るなら「全マップを削除」で確認してから追加してください。未編集の初期空マップを置き換え、6枚だけになります。「戻す」で復元できます。[world.json](./world.json) の読み込みでも編集全体を置き換えられます。

| ID | マップ | 大きさ | 内容 |
|---|---|---|---|
| 0 | 小さな城 | 7×7 | 王様、玉座、街への出口 |
| 1 | 小さな街 | 17×11 | 武器・防具・道具の3店、素材交換、民家 |
| 2 | 小さな世界 | 16×16 | 海、砂浜、草地、山、4つの入口 |
| 3 | 小さな森 | 9×9 | 妖精、木、木の盾の宝箱、通常敵3種 |
| 4 | 小さな洞窟 | 9×9 | 魔女、銅の剣の宝箱、通常敵3種 |
| 5 | 小さな魔王城 | 7×8 | 玉座、魔王、勝利でGAME CLEAR |

城→街→全体マップから各場所へ入り、帰還できます。境界の出口は1マス突き出す床で示します。会話はテンプレートID、敵・道具・装備の能力と素材交換はWeb共通configを使います。王様は小型版のみ1%の隠し遭遇（通常版・巨大版は0.01%）。森の敵ID 1〜3は12%、洞窟の5〜7は14%（比率5:3:2）。王様の撃破をクリア条件にしません。

現公開先 `https://tag-quest-kappa.vercel.app/` の容量は次のとおりです。

| 内容 | 計算値 |
|---|---:|
| TQ v14 compactバイナリ | 302B |
| Base64urlハッシュ | 403文字 |
| 公開URL全体 | 439B |
| 単一NDEF URI・TLV・終端込み | 444B |
| 追加予約5B込み | 449B / 496B |
| 予約後の残り | 47B |

URL450B以下・NDEF/TLV455B以下を検証で保証します。現公開先ではNDEF/TLV領域に52B、追加予約5Bを引いても47Bの余裕があります。バイナリ目標300Bは2B超えますが、実URLの容量目標を優先します。ドメインを長くしたり、自由文・配置・追加レコードを増やす場合は、エディタで容量を再確認します。2026-10-13にユーザーの実機NTAG215で、この小型版の書き込みと起動成功が報告されました。

正本は [adventure-small.json](../../compiler/maps/adventure-small.json)。`web/` で `npm run export:adventure -- small`、または `npm run export:demos` で、JSON・バイナリ・容量レポート・URL・6枚のPNGを再生成します。容量の正本は [world.report.json](./world.report.json)、起動URLは [world.url.txt](./world.url.txt)、全景は [world.png](./world.png) と [town.png](./town.png) を参照してください。

`verify:demos` はPython/Webの一致とURL復元、全マップへの実移動、宝箱取得、魔王戦からクリア・帰還・初期化、予約込み容量を検証します。従来の城＋街だけの199B見本は [art/nfc](../nfc/README.md) に別で残します。

小型版でも「消えた灯火」の会話と結末を持ちます。森の妖精と洞窟の魔女を訪ね、魔王城へ向かいます。画面上部と「つよさ」で次の目的を確認でき、クリア後には後日談が変わります。本文はWeb側のテンプレートに保管し、NFCに長文を保存しません。敗北ではG半減、所持品・経験値は保持して復活します。


## 実タグ向けの容量余裕（2026-10-13）

旧URL482B／NDEF/TLV487Bでは実タグへの書き込み失敗が報告されたため、6マップ・3店舗と店員・妖精・魔女・2個の宝箱・魔王戦・森と洞窟の通常敵3種ずつを残し、バイナリを32B削減しました。

| 削減箇所 | 旧 | 新 | 削減 |
|---|---:|---:|---:|
| 城の床 | 20B | 11B | 9B |
| 魔王城の床 | 25B | 16B | 9B |
| 洞窟の床 | 21B | 15B | 6B |
| 城の遭遇設定 | 6B | 2B | 4B |
| 民家の個別会話 | 4B | 0B | 4B |

城・魔王城は壁を既定値にして、内床・下端の空白・中央カーペットの3矩形で同じ全タイルを復元します。洞窟は壁を既定値とする広間・下端の空白・出口の通路の3矩形へ整理します。魔女・宝箱・出口への実移動を検証し、民家はWeb共通の施錠メッセージを使います。小型版の王様だけ1%の整数確率にして、小数確率用のv15を不要にしました。通常版・巨大版は別データとして、現在は0.01%に下げています。

2026-10-13に、この新URLをユーザーのNTAG215へ書き込み、起動まで成功したと報告されました。旧URLのデータは自動で書き換わりません。この確認は使用したタグに対するもので、ドメインやデータを変更する場合は容量を再計算してください。


通常版・巨大版の探索拡充では、この小型版の正本・バイナリ・起動URLを変更していません。verify:demosで実機確認済みバイナリのSHA-256 `183209444663027a9a3e0308fac0513ada6a0cfa1775f7dcacd8db08cba2950c` を照合し、302Bの内容を保持します。共通の既存会話・敵・アイテム・スキル設定も今回は変更していません。

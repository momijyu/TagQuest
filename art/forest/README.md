# 草原と森のドット素材

- 草：街の `web/src/data/tiles/town-grass.ts` を共用（16×16・4色）。
- 森の地面：`web/src/data/tiles/forest-ground.ts`（16×16・6色）。苔と茶色い落ち葉の床。
- 木：`web/src/data/objects/tree.ts`（48×48・10色）。広葉樹の葉・幹・根。

色パレットと整数座標から作るピクセル配列が正本です。PNGは確認用で、ゲームではコードから描きます。
`web/` で `npm run export:forest-pixels` を実行すると、原寸3枚と3倍の並び見本 `preview.png` を再出力できます。
見本の配置は `web/src/renderer/forest-preview.ts`。実際のステージはエディタで作ります。

木は3×3マスの配置枠を持ち、中央下の1×1マスだけが通行不可。エディタの「建物・家具」で配置できます。
木を調べるメッセージとアイテムは、既存オブジェクトと同じ設定欄から指定できます。

木は幹の足元の下端を基準に奥から手前へ描きます。主人公が木の後ろなら葉に隠れ、手前や幹の横の同じ奥行きなら主人公を手前に描きます。この描画順はWeb側で計算し、NFCに追加のレイヤー情報を保存しません。

## 森の中のマップ

`compiler/maps/forest.json` に19×17マスのステージを用意しています。曲がった土の道、草の広場、池、15本の木とやくそうのキラキラを配置しています。出現モンスターは未指定です。Web側はモンスター素材・ステータスの保管場所とし、敵IDと出現率はNFCに保存するステージ設定から指定します。
紹介画面の「森の中」と「歩いてみる」で確認できます。`npm run export:forest-pixels` は2倍の全景 `stage.png` も出力します。
全体マップへの往復は `compiler/maps/adventure-connections.json` で指定し、[接続した見本](../adventure/README.md) に組み込みます。

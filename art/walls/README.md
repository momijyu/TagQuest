# 配置に合わせて向きが変わる壁

エディタでは「城の壁」「魔王城の壁」をそれぞれ1種類として選んで塗ります。周囲8マスの同じ壁と床を見て、上・下・左右・角・壁の内側・単独の柱状の見た目を自動で選びます。塗り直す、消す、戻すと隣の壁の見た目も描き直します。洞窟の岩壁はすでに1種類で、既存の床との境目の描画を維持します。

JSON／NFCには城＝`wall-top`（ID 2）、魔王城＝`demon-wall-top`（ID 20）だけを保存します。Webに残した見た目のパーツから向きを選ぶため、向きや角のデータは追加しません。統合表は `web/src/data/wall-families.json`、描画は `web/src/renderer/wall.ts`。旧JSONの左右・角の名前は同じ素材へ変換し、旧バイナリのIDも認識します。旧IDは互換用に残し、エディタの素材選択からは隠します。床の選択肢は従来の25から17種類へ減ります。

境界は配置された床と壁で判断し、NPCや家具で壁の向きは変えません。空白とマップ外は部屋の床として数えません。壁の通行不可の1×1マス判定はそのままです。素材自体の石目と色・明暗を維持し、下側の壁は石積みの絵全体を反転せず縁だけ向きを変えています。

見本の城では重複していた角の指定を除き、城51B・街151B・共通4B＝206B（以前は212B）になりました。接続した6マップは954B（以前は970B）。各マスの基本の保存幅が5分の1になるという意味ではなく、同じ壁IDが続くことや長方形指定・床ID表が減ることで短くなります。保存容量はエディタで実データから計算します。

`web/` の `npm run export:walls` で見本を再出力できます。`automatic.png` は上が城、下が魔王城で、左から入口付きの部屋・太い壁・交差する壁です。`npm run verify:walls` で8方向と角・接続と単独／厚い壁・取り消し・通行不可・旧名前／ID・WebとPythonの一致を確認します。見本のPNGを目視確認しています。実ブラウザ／スマホでの目視確認は未実施です。

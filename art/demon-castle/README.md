# 魔王城の内部

17×19マスの玉座の間です。下の入口から紫のカーペットを進み、奥の玉座へ到達できます。左右に6本の石柱を配置しています。玉座の手前に魔王NPCを配置し、話しかけて敵ID 4との戦闘に移ります。勝利で魔王が消えてGAME CLEAR、逃走・敗北なら再戦できます。ランダム敵は未指定で、NFCのステージ設定から指定できます。

## 素材と編集

- 床・カーペット・壁：`web/src/data/tiles/demon-castle.ts`。16×16のピクセル配列とパレット。
- 柱・玉座：`web/src/data/objects/demon-castle.ts`。既存の城と同じドットの形を使い、紫灰色の石柱と金・紫の玉座へ色を変えています。
- 配置：`compiler/maps/demon-castle.json`。
- 全体マップとの接続：`compiler/maps/adventure-connections.json`。
- 確認用描画：`web/src/renderer/demon-castle-preview.ts`。

カーペットの金の縁は外周だけに描き、隣のカーペットとの間には線を入れません。岩床とカーペットは歩けて、壁は通行不可です。柱は1×2マスの枠をふさぎます。玉座は3×2マスの編集枠と24×24の描画で、当たり判定は中央の横1×縦2マス。側面を歩けて、正面から調べられます。

エディタの「床・壁」と「建物・家具」で素材を選べます。柱と玉座には既存のメッセージ・アイテム設定を利用できます。「＋ 接続した冒険の見本」は6マップを空きIDへ割り当てて追加し、既存の編集内容を保持します。

## 試遊と接続

紹介画面の「魔王城」で素材と全景、「歩いてみる」の「魔王城」で歩行を確認できます。全体マップからも入れます。座標は0始まり、到着位置は主人公の足元です。

| 接続 | 出口 | 到着 | 向き |
|---|---|---|---|
| 全体マップ → 魔王城 | (23,4) | (8,17) | 上 |
| 魔王城 → 全体マップ | (8,18) | (23,5) | 下 |

帰りは全体マップの入口の前へ到着します。

## 出力と容量

`web/` の `npm run export:demon-castle-pixels` で各原寸素材と2倍の `stage.png` を再出力します。PNGは確認用で、ゲームは同じピクセル配列から描画します。

`npm run export:adventure` で6マップのJSON・バイナリ・レポート・仮URLを `art/adventure/` へ出力します。魔王城はTQ v11で89B（床46B・配置16B・ヘッダー9B・会話／取得設定6B・出口7B・エンカウント／イベント5B）。6マップ合計708B、仮URL966B・NDEF/TLV971Bです。容量の正本は `art/adventure/world.report.json`。

床IDは18〜24、配置IDは26〜27を末尾に追加し、以前のIDを維持します。従来の城・街の初期バイナリは206Bのままです。URLからの起動に対応しています。NFC向けの容量調整・実機読み書きは未完了です。

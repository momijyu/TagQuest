# モンスターのドット素材

草原・森の3体は原案イラストの構成を参考に、床・住民と同じ `PixelSprite` の形式で描いた素材です。原案PNGの縮小・減色ではありません。魔王は同じ形式の新しいデザインです。

草原・森の3体の正本は `web/src/data/encounters/enemy-pixels.ts`、魔王は `web/src/data/characters/demon-lord.ts`。整数座標へ色を置き、色パレットとピクセル配列を作ります。`drawSprite` で1ドットずつ描き、戦闘では2倍の整数倍率・補間なしで表示します。

| 素材 | 原寸 | パレット | 残した特徴 |
|---|---|---|---|
| `leaf-gel.png` | 48×48 | 12色 | 3枚の葉・ゼリーの体・丸い腕 |
| `ghost-mushroom.png` | 48×48 | 12色 | 赤い傘と斑点・傘の裏・根の手足 |
| `forest-wolf.png` | 64×48 | 16色 | 緑のたてがみ・金色の目・巻いた尾・低い4本足の姿勢 |
| `demon-lord.png` | 64×56 | 16色 | 金の角兜・黒紫の鎧・赤いマント・長剣 |

このフォルダのPNGはコードから書き出した確認用です。`preview.png` は4体を4倍で並べた見本。絵を修正した後は `web/` で `npm run export:enemy-pixels` を実行すると作り直せます。原寸PNGの透過は完全な0／255で、半透明やアンチエイリアスはありません。

元のイラストは `web/src/assets/enemies/` にそのまま保持します。紹介画面ではドット版を主表示にし、「参考イラスト」を開いた場合だけ原案を読み込みます。草原・森の3体の名前・敵ID・能力・行動・報酬は維持します。魔王は新しい敵ID 4で追加し、詳しくは [魔王の記録](../../demon-lord/README.md) にまとめています。NFCの形式は変更しません。

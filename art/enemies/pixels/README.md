# モンスターのドット素材

草原・森の3体は原案イラストの構成を参考に、床・住民と同じ `PixelSprite` の形式で描いた素材です。原案PNGの縮小・減色ではありません。洞窟の3体と魔王も同じ形式の新しいデザインです。

草原・森の3体の正本は `web/src/data/encounters/enemy-pixels.ts`、洞窟の3体は `web/src/data/encounters/cave-enemy-pixels.ts`、魔王は `web/src/data/characters/demon-lord.ts`。整数座標へ色を置き、色パレットとピクセル配列を作ります。`drawSprite` で1ドットずつ描き、戦闘では2〜3倍の整数倍率・補間なしで表示します。

| 素材 | 原寸 | パレット | 残した特徴 |
|---|---|---|---|
| `leaf-gel.png` | 48×48 | 12色 | 3枚の葉・ゼリーの体・丸い腕 |
| `ghost-mushroom.png` | 48×48 | 12色 | 赤い傘と斑点・傘の裏・根の手足 |
| `forest-wolf.png` | 64×48 | 16色 | 緑のたてがみ・金色の目・巻いた尾・低い4本足の姿勢 |
| `cave-bat.png` | 64×48 | 8色 | 紫の翼・大きな耳・金色の目・牙 |
| `rock-hermit.png` | 64×48 | 10色 | 岩の殻・茶色のハサミ・金色の目 |
| `crystal-lizard.png` | 64×48 | 11色 | 背中の水晶・青灰色の体・巻いた尾 |
| `demon-lord.png` | 64×56 | 16色 | 金の角兜・黒紫の鎧・赤いマント・長剣 |
| `demon-guard.png` | 64×56 | 16色 | 魔王と同じドットの輪郭を基にした青マント・鉄の兜 |

このフォルダのPNGはコードから書き出した確認用です。`preview.png` は13体を4倍で並べた見本。絵を修正した後は `web/` で `npm run export:enemy-pixels` を実行すると作り直せます。原寸PNGの透過は完全な0／255で、半透明やアンチエイリアスはありません。

元のイラストは `web/src/assets/enemies/` にそのまま保持します。紹介画面ではドット版を主表示にし、「参考イラスト」を開いた場合だけ原案を読み込みます。草原・森の3体の名前・敵ID・能力・行動・報酬は維持します。魔王は新しい敵ID 4で追加し、詳しくは [魔王の記録](../../demon-lord/README.md) にまとめています。NFCの形式は変更しません。

橋の子分の正本は `web/src/data/characters/demon-guard.ts`。元の魔王のピクセル配列を変更せず、色の異なる派生として立ち姿32×32と戦闘用64×56を保持します。

はぐれクリスタルは32×32・5色の水晶形のドットです。戦闘で3倍描画し、他の敵と同じ足元へ揃えます。古代の虚無神は魔王の輪郭を銀紫と青白い光に置き換えた64×56・16色で、フィールド立ち姿とパレットを共有します。正本は `characters/void-god.ts`。

第2部の虚影の翼獣・裂け目の魔狼・深淵の番人は既存の翼獣・狼・岩のモンスターの形を保ち、紫・青白い光のパレットへ変えた別素材です。既存素材のピクセルとパレットは変更しません。コードはenemy-pixels.tsに登録し、専用JSONからbattleImageとして参照します。

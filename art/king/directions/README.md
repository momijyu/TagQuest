# 主人公ベースの王様の4方向

装備中の正面は、以前作った `web/src/assets/king/king-standing-hero-style-64.png` をそのまま使います。左右・後ろは `web/src/assets/player/hero-sheet-64.png` の方向素材をベースにし、`web/src/data/characters/king-directions.ts` で髪を銀色、青い服を赤へ置換し、小さな三山の王冠と短いあごひげを足します。原寸はすべて64×64です。元の頭身・輪郭・髪の形と陰影・目・肌・ズボン・ブーツを保ちます。新しい画像生成は使用していません。

Webでは主人公の画像を読み込んだ後、元のピクセルをCanvasで取得して方向別の王様へ変換します。王の3点セット装備中の歩行に使い、ゲーム上の描画はすべて32×32のままです。城のNPCと戦闘の王様は従来の年配の正面素材を使います。

`web/` で `npm run export:king-pixels` を実行すると `front.png`・`back.png`・`left.png`・`right.png` と `preview.png` を出力します。原寸PNGは透過、見本は4倍の整数倍率で正面・後ろ・左・右の並びです。Webと書き出しは同じ色変更処理を利用します。見本を目視確認し、元画像・目や肌・下半身の保持、4方向の切り替えと装備解除は自動テストで確認しています。実ブラウザ／スマホでの目視確認は未実施です。

前回の絵柄が合わなかった32×32版は `rejected-v1/` に画像とソースを保管しています。

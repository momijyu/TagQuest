# 王様の左右・後ろ姿

正本は `web/src/data/characters/king-directions.ts` の32×32ピクセルと16色パレットです。画像生成は使わず、既存の正面立ち姿の金の王冠・白髪と白ひげ・赤いマントと白い斑点付きの縁・クリーム色の服・茶色のブーツを参考にコードで描いています。左向きは右向きの反転です。正面・座り姿・過去の試作は変更していません。

Webでは起動時にピクセルを透過Canvasへ描いて方向ごとの画像にし、王の3点セットを着た主人公の移動方向へ対応させます。正面の既存64×64画像も、新しい方向素材も、ゲーム上は同じ32×32の枠に描きます。NPCの王様と戦闘の王様は従来の正面素材です。

`web/` で `npm run export:king-pixels` を実行すると `back.png`・`left.png`・`right.png` と `preview.png` を再生成します。原寸PNGは透過、見本は8倍の整数倍率、並びは後ろ・左・右です。書き出した見本を目視確認し、ゲームの方向切り替え・中央位置・装備解除はDOM／Canvasの自動テストで確認しています。実ブラウザ／スマホでの目視確認は未実施です。

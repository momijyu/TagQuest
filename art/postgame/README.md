# 第2部：虚無の回廊

[全景](./void-realm.png)。19×23マスで、最奥に古代の虚無神、南端に帰還の裂け目を配置しています。魔王撃破後にWebエンジンが追加する共通のクリア後マップです。

正本は `web/src/game/postgame.ts`。各冒険のバイナリ・起動URLには含めず、`world.ts` が玉座奥に入口を作り、空きマップIDと帰還先を割り当てます。元の配置データは変更しません。初期化で追加マップと裂け目を消し、再開時はクリアフラグから復元します。

`npm --prefix web run export:demos` または `export:adventure` でこのPNGも再生成します。虚無神の立ち姿は32×32、戦闘用は64×56の整数ピクセルと16色パレットです。

左右の広間と回廊の足元は通行可能。新しい通常敵は虚影の翼獣・裂け目の魔狼・深淵の番人の3体で、6%・45:35:20の割合です。HP150〜300の範囲、経験値120〜200で育成できます。

虚無神はHP1200・攻撃55・防御25・魔力55、2回行動。虚無の爪痕→虚無の波動→深淵の闇を続けて読みます。報酬のオーブはHP100・MP50・攻撃30・防御30・魔力30。クリアと撃破の状態から真のクリアを記録し、タイトルへ表示します。

# 巨大な世界：15マップの冒険見本

通常版の6マップを土台に、北・東の大陸、2つ目の城と王様・市場・森・洞窟、古城の遺跡・海辺の集落・妖精の花園を追加した固定ワールドです。総面積8,367マスで、通常版2,418マスの約3倍。宝箱は27個です。地形や配置をランダム生成せず、編集した内容をそのまま保存します。

紹介画面の「歩いてみる」→「巨大な世界」で遊べます。開始マップを選んでも、15マップすべての接続を維持します。「この世界の起動URL」はデータ入りのプレイ専用画面を開きます。

エディタでは「＋ 巨大な世界（15マップ）」で追加します。編集中のマップを残し、IDと出口の参照を割り当て直します。「全マップを削除」で確認後に残る未編集の空マップは、見本追加時に置き換えます。「戻す」で復元できます。見本だけを直接開く場合は [world.json](./world.json) を「JSONを開く」から読み込みます。

城→街→南の大陸→北の大陸→東の大陸→魔王城が主な導線です。通常版と違い、南の大陸の旧魔王城入口は北への入口になります。北の市場から北の城へ入り、2つの森・洞窟・遺跡・集落・花園へ寄り道して、帰還できます。各森は敵ID 1〜3を12%、各洞窟は5〜7を14%で抽選します（比率5:3:2）。南の王様は0.1%の隠し遭遇です。北の王は会話専用で、南の王様の撃破では消えません。

正本は [adventure-large.json](../../compiler/maps/adventure-large.json)。通常版の後の変更は自動コピーせず、このJSONを編集します。敵・アイテム・素材交換の性能はWeb共通configを参照します。

`web/` で `npm run export:adventure -- large`、または3種まとめて `npm run export:demos` を実行すると、JSON・バイナリ・レポート・URL・15枚のPNGを再生成します。[海辺の集落](./seaside-town.png)、[妖精の花園](./fairy-garden.png)、[北の城](./north-castle.png)、[北の大陸](./north-world.png)、[水晶の洞窟](./crystal-cave.png)、[東の大陸](./east-world.png)、[遺跡](./ruins.png) で全景を確認できます。

現公開先でバイナリ1,804B・URL2,442B・NDEF/TLV2,447B。NTAG215の496Bには収まらず、ブラウザ試遊・URL共有用です。計算の正本は [world.report.json](./world.report.json)。NFCへ収める場合は [小型版](../adventure-small/README.md) を使います。

物語「消えた灯火」は、妖精と魔女→北の王→奥深い森と水晶の洞窟→古城の書記→魔王へつながります。王が援軍を出さなかった過去と守護者の誓いをたどり、灯火を取り戻します。「つよさ」に次の目的を表示しますが、会話を移動・戦闘の必須条件にはしません。クリア後は後日談の会話を聞いて帰還できます。本文・話者・後日談はWeb共通の [会話テンプレート](../../web/src/data/dialogue-templates.json)、目的と結末は [物語config](../../web/src/data/adventure-story.json) を参照します。敗北ではG半減、所持品・経験値保持で復活します。

魔王城の南 `(24,22)` の入口は「古城の遺跡」です。以前の街アイコンを専用の崩れた石塔に置き換え、接続先ID 11を維持します。新しい集落は南西 `(8,27)` の街アイコンから入れます。花園は奥深い森の最上行 `(15,0)` の1マス出口から入り、集落・花園の下端は出口の床だけを1マス突き出しています。集落・花園には遭遇表を設定しません。通常の森・洞窟の出現表と隠し王様は維持します。

[道しるべ・水晶・石碑・花の草地・遺跡の石畳](../adventure-materials/README.md) を追加し、各地の案内・誓いの石碑・水晶の残響に定型文ID 60〜71を使います。新しい住民にもクリア後の会話があります。既存NPCの道の中央への配置は増やさず、水晶と宝箱は中央の部屋にも配置し、狭い通路を空けます。新しいIDは一覧の末尾に追加し、旧データのIDを維持します。検証では新規会話・オブジェクト・宝箱・出口への到達、帰還・クリアと後日談、旧形式とPython/Webの一致を確認します。


妖精の花園側の看板は専用の定型文ID71を使い、南の小道が奥深い森へ戻ることを案内します。森側のID66は「北：妖精の花園」のままです。北の王と森の証人は、水晶の洞窟が東の橋を渡った東の大陸の北西にあることを伝えます。会話本文はWeb共通なので、案内の補足でNFCの容量は増えません。

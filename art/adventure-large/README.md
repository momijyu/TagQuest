# 巨大な世界：28マップの冒険見本

通常版の6マップを土台に、北・東の大陸、2つ目の城と王様・市場・森・洞窟、古城の遺跡・海辺の集落・妖精の花園を追加した固定ワールドです。総面積14,230マスで、通常版5,515マスの約2.6倍。宝箱は50個です。地形や配置をランダム生成せず、編集した内容をそのまま保存します。

紹介画面の「歩いてみる」→「巨大な世界」で遊べます。開始マップを選んでも、28マップすべての接続を維持します。「この世界の起動URL」はデータ入りのプレイ専用画面を開きます。

エディタでは「＋ 巨大な世界（28マップ）」で追加します。編集中のマップを残し、IDと出口の参照を割り当て直します。「全マップを削除」で確認後に残る未編集の空マップは、見本追加時に置き換えます。「戻す」で復元できます。見本だけを直接開く場合は [world.json](./world.json) を「JSONを開く」から読み込みます。

城→街→南の大陸→北の大陸→東の大陸→魔王城が主な導線です。通常版と違い、南の大陸の旧魔王城入口は北への入口になります。北の市場から北の城へ入り、2つの森・洞窟・遺跡・集落・花園へ寄り道して、帰還できます。各森は敵ID 1〜3を9%（比率5:3:2）、各洞窟は5〜7とレア敵10を12%（比率50:30:20:5）で抽選します。南の王様は0.01%の隠し遭遇です。北の王は会話専用で、南の王様の撃破では消えません。

正本は [adventure-large.json](../../compiler/maps/adventure-large.json)。通常版の後の変更は自動コピーせず、このJSONを編集します。敵・アイテム・素材交換の性能はWeb共通configを参照します。

`web/` で `npm run export:adventure -- large`、または3種まとめて `npm run export:demos` を実行すると、JSON・バイナリ・レポート・URL・28枚のPNGを再生成します。[海辺の集落](./seaside-town.png)、[妖精の花園](./fairy-garden.png)、[北の城](./north-castle.png)、[北の大陸](./north-world.png)、[水晶の洞窟](./crystal-cave.png)、[東の大陸](./east-world.png)、[遺跡](./ruins.png) で全景を確認できます。

現公開先でバイナリ3,082B・URL4,146B・NDEF/TLV4,151B。NTAG215の496Bには収まらず、ブラウザ試遊・URL共有用です。計算の正本は [world.report.json](./world.report.json)。NFCへ収める場合は [小型版](../adventure-small/README.md) を使います。

物語「消えた灯火」は、妖精と魔女→北の王→奥深い森と水晶の洞窟→古城の書記→魔王へつながります。王が援軍を出さなかった過去と守護者の誓いをたどり、灯火を取り戻します。「つよさ」に次の目的を表示しますが、会話を移動・戦闘の必須条件にはしません。クリア後は後日談の会話を聞いて帰還できます。本文・話者・後日談はWeb共通の [会話テンプレート](../../web/src/data/dialogue-templates.json)、目的と結末は [物語config](../../web/src/data/adventure-story.json) を参照します。敗北ではG半減、所持品・経験値保持で復活します。

魔王城の南 `(24,22)` の入口は「古城の遺跡」です。以前の街アイコンを専用の崩れた石塔に置き換え、接続先ID 11を維持します。新しい集落は南西 `(8,27)` の街アイコンから入れます。花園は奥深い森の最上行 `(15,0)` の1マス出口から入り、集落・花園の下端は出口の床だけを1マス突き出しています。集落・花園には遭遇表を設定しません。通常の森・洞窟の出現表と隠し王様は維持します。

[道しるべ・水晶・石碑・花の草地・遺跡の石畳](../adventure-materials/README.md) を追加し、各地の案内・誓いの石碑・水晶の残響に定型文ID 60〜71を使います。新しい住民にもクリア後の会話があります。既存NPCの道の中央への配置は増やさず、水晶と宝箱は中央の部屋にも配置し、狭い通路を空けます。新しいIDは一覧の末尾に追加し、旧データのIDを維持します。検証では新規会話・オブジェクト・宝箱・出口への到達、帰還・クリアと後日談、旧形式とPython/Webの一致を確認します。


妖精の花園側の看板は専用の定型文ID71を使い、南の小道が奥深い森へ戻ることを案内します。森側のID66は「北：妖精の花園」のままです。北の王と森の証人は、水晶の洞窟が東の橋を渡った東の大陸の北西にあることを伝えます。会話本文はWeb共通なので、案内の補足でNFCの容量は増えません。


## 住宅通りと寄り道（2026-10-13）

街・北の市場・海辺の集落の東側に赤い家と青い家を追加し、レンガの脇道と南の通りをつなぎました。青い家では上やくそうを一度だけ受け取れます。森の木陰と林の広場、洞窟の左右の横穴には各2個の宝箱を追加しています。

水晶の洞窟には左右に2つの横穴を作り、森狼のベストとどくけし丸の宝箱、水晶の記録を配置しました。遺跡には壁の残る工房跡と、羽のお守り・水晶の杖の宝箱を追加しています。書記は壁の手前を避けて中央通路の脇へ移しました。会話は新規ID72〜77を使い、通常版・小型版の既存会話や性能設定へ変更を加えません。


## 辺境と橋の子分（2026-10-13）

北の大陸の北端（7,0）から辺境の大陸へ進めます。中央の橋には敵ID8「魔王の子分」を置きました。青いマントと鉄の兜のドットで、南側・北側から話しかけて戦闘を始めます。HP90／攻撃14／防御4、剣の攻撃と盾の体当たりを交互に行い、逃走も可能です。倒すと180G・180EXP・上やくそう2個・まほうの水1個を受け取り、子分が消えて中央の橋を通れます。逃走・敗北では残り、再戦できます。往復で復活せず、最初からで復元します。

東側には見張りのいない長い迂回路を用意しています。子分を倒さなくても新しい森・砦を探索でき、本来の魔王がいる東の大陸への道も従来どおりです。GAME CLEARになるのは従来の魔王戦だけです。新しい場所の会話はID78〜84、場所名はWeb側の会話テンプレートlocationNameから補います。旧会話・通常版・小型版のマップや確率は変更しません。

全景は [辺境の大陸](./frontier-world.png)、[風渡りの森](./frontier-forest.png)、[忘れられた砦](./forgotten-fort.png)。敵の強さ・行動・報酬は [demon-guard.json](../../web/src/data/encounters/enemies/demon-guard.json) で編集できます。

南・北・海辺の街へ宿屋の主人、南の街へ出口案内、洞窟2種へはぐれクリスタルを追加しました。店売りの基本装備と近くの宝箱報酬を区別しています。クリア後の虚無の異空間はWeb側で生成し、保存binには含めません。

巨大版の通常遭遇率は森3か所9%・洞窟2か所12%へ1.5倍に調整しました。王様0.01%と戦闘後の安全6歩は維持します。確率は起動URLのデータに含まれるため、更新後のworld.url.txtを使って反映してください。

## 危険地域の拡張（2026-10-14）

湿原・霊峰・火山と、それぞれの巣窟を追加しました。ID18〜23が追加分で、本編の接続と宝箱の数は維持します。近郊の草原にはLv1〜5の敵、危険地域には推奨Lv15〜22／25〜35／35〜45の敵を配置し、入口の看板と画面に警告を表示します。

街の民家3軒を宿屋・酒場・教会へ改装し、NPCの宿泊・賞金首報告・毒治療を実装しました。湿原の魔女の小屋で新しい素材を強化薬や霊薬に交換できます。主ID15〜17は各世界で一度きりの勝負・報酬・消失、ギルドで追加報酬と称号を一度だけ受け取れます。進行と報告は自動保存し、称号・所持品は別世界へ引き継ぎます。

追加の正本は [danger-regions.json](../../compiler/maps/danger-regions.json)、組み立ては [world-expansion.ts](../../web/src/editor/world-expansion.ts)。既存の基本マップと分離して、通常・巨大版だけに呼び出します。小型版の元データとバイナリは変更しません。新しい地形はランダム生成ではなく固定配置です。

全景： [湿原](./poison-marsh.png)、[蜘蛛の毒巣](./arachne-nest.png)、[霊峰](./frost-peak.png)、[氷狼の洞穴](./fenrir-nest.png)、[火山](./burning-battlefield.png)、[紅蓮の竜穴](./volkex-nest.png)。

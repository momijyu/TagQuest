# 全体マップの見本

参考画像の海岸・草原・山脈・森・川の構成を、既存のドット素材に合わせて32×24マスに試作しました。

- `web/src/data/tiles/world-sea.ts`：海・川、16×16・4色。
- `web/src/data/tiles/world-sand.ts`：砂浜、16×16・4色。
- `web/src/data/objects/world-terrain.ts`：山（6色）・森の記号（6色）、各16×16。
- `web/src/data/objects/world-locations.ts`：街・森の入口・洞窟・魔王城・古城の遺跡、各32×32。入口枠は1×1マス。
- 草原と森の地面は既存の素材を共用。森の内部で使う48×48の木は別素材として維持します。
- 配置：`compiler/maps/world.json`。海を既定床にし、床の範囲と地形記号の位置を記録します。

PNGはコードから出力する確認用です。`web/` で `npm run export:world-pixels` を実行すると地形4枚・場所5枚の原寸PNG、4倍の場所一覧 `locations.png` と2倍の全景 `preview.png` を再出力します。
砂浜の海に接する縁と川を渡る橋の向きは、実際の床の隣接関係から描きます。

紹介画面の「全体マップ」で全景を確認し、「歩いてみる」のマップ選択で歩行できます。
エディタの「＋ 全体マップの見本」で、編集中のマップへ新しいIDで追加できます。「戻す」で追加だけ取り消せます。
海と山は通行不可、草原・砂浜・森・橋は通行可能です。街・森の入口・洞窟・魔王城を仮配置しています。場所の絵は入口に中央揃えで上へはみ出し、入口は歩けます。
紹介画面のプレイでは[接続した冒険の見本](../adventure/README.md)を使い、街・森・洞窟・魔王城へ入って戻れます。全体マップ単体のJSONは出口なしを維持し、接続した見本では `compiler/maps/adventure-connections.json` の透明な出口を重ねます。

保存座標のマスは0始まりで、街 `(8,15)`、森 `(7,13)`、洞窟 `(12,12)`、魔王城 `(23,4)`。洞窟正面の山を1個除き、4か所とも開始地点から歩いて到達できるようにしています。

この見本は地形の配置確認用で、NFC容量の目標へは未調整。単体493B、既存の城・街と合わせて701Bです。

巨大版の東の大陸で使う古城の遺跡は `world-ruins.png`。屋根のない崩れた石塔・暗いアーチ・苔を描き、街の家とは区別します。入口は `(24,22)`、接続先は古城の遺跡（ID 11）です。通常の全体マップ見本の4入口は維持します。

# 経験値・レベル・習得と装備制限の編集

JSONを保存してゲームページを再読み込みすると反映します。設定はWeb側で共通管理し、NFCの保存容量は増えません。

## 技を覚えるレベル

`skill-catalog.json` の技に `learnLevel` を指定します。

```json
{
  "id": 3,
  "name": "氷の矢",
  "kind": "spell",
  "description": "鋭く尖った冷気の矢を撃ち放ち、敵の急所を射抜く氷結魔法。",
  "learnLevel": 3,
  "mpCost": 4,
  "effect": { "type": "magic-damage", "amount": 18, "magicScale": 0.4 }
}
```

`encounters/player-config.json` の `skills` にもIDを登録します。`"skills": [0, 1, 2, 3]` なら、このうち習得レベルに達した技だけ使えます。ID 3はレベル3で自動習得し、レベルアップ時に通知します。「つよさ」で習得済みの技を確認できます。未習得の技は「???」で表示し、名前・効果・必要MP・習得レベルは習得するまで隠します。`skills` にない技はレベルを上げても覚えません。`learnLevel` は1〜99、省略すると1です。強打・火の玉・癒しは従来どおりLv1、追加魔法10種はLv3〜80、上位物理特技4種はLv8・18・36・50で習得します。

## 装備できるレベル

`item-catalog.json` の装備に `requiredLevel` を指定します。

```json
"equipment": { "slot": "weapon", "attack": 12, "defense": 0, "requiredLevel": 5 }
```

レベル5から装備できます。低いレベルでも購入・取得・所持・売却はできますが、装備はできません。店と装備一覧に必要レベルを表示します。値は1〜99、省略すると1です。基本装備はLv1、鉄の兜はLv4、魔導の三角帽子はLv3に設定しています。武器そのものは購入・取得して使います。

## 敵を倒して得る経験値

`encounters/enemies/` 内の敵JSONの `reward` に `experience` を指定します。

```json
"reward": { "gold": 0, "experience": 20, "items": [] }
```

1戦につき0〜999999の整数。省略すると0、`reward: null` でも獲得しません。勝利画面に獲得量を出し、勝利が確定した時点で一度だけ付与・保存します。保存しない試遊では勝利画面を閉じる際に付与します。逃走・敗北では付与しません。王様の報酬は900EXPで、現在の成長表では経験値0・レベル1からレベル10になります。成長表を変更してレベル10の必要経験値を変える場合は、王様の `reward.experience` も合わせて変更してください。

## 必要経験値と能力の成長

`progression-config.json` の先頭10レベルの例（正本には99レベル分を記載）：

```json
{
  "levelThresholds": [0, 15, 40, 80, 140, 220, 330, 470, 650, 900],
  "growthPerLevel": { "hp": 5, "mp": 2, "attack": 2, "defense": 1, "magic": 2 }
}
```

`levelThresholds` は各レベルに到達するための**累計経験値**です。レベル1＝0、2＝15、3＝40。レベルアップで経験値は消費しません。現在レベルと累計経験値、次のレベルまでの残量をゲーム内で表示します。一度に多く獲得すれば複数レベル上がります。

配列の件数が最高レベルです。現在の正本は99件で上限Lv99です。Lv11以降の累計必要経験値は `10 × レベル × (レベル − 1)` で、Lv10は従来の900EXP、Lv99は97,020EXP。上の抜粋だけを設定した場合は上限Lv10になります。最初は0、以降は前の値より大きい整数を並べ、最大99レベルまで増やせます。各閾値・累計経験値の上限は999999999です。最高レベルでも経験値はこの上限まで増えます。最高レベルより先の習得・装備条件を設定しても到達できないので、成長表と合わせて設定してください。

`growthPerLevel` は1レベル上がるごとの最大HP・最大MP・攻撃力・防御力・魔力の増加量で、各0〜9999です。能力の上限は9999。装備補正は成長後の基礎能力へ加算します。`player-config.json` の `stats` と `maxMp` はレベル1の基礎値です。レベルアップ時は成長・装備後の最大HP／MPまで全回復します。毒状態は維持し、治療アイテムや宿泊で治せます。能力の増加と新しく覚えた技はフィールドに戻った後のメッセージで確認できます。

開始時の経験値は `encounters/player-config.json` の `initialExperience`（省略時0）です。例えば40ならレベル3の能力・満タンのHP／MPと、そのレベルまでの習得技で開始します。開始レベルは経験値から計算するので直接の `level` 指定は不要です。

レベル・経験値は同じプレイ中のステージ移動・逃走・敗北で引き継ぎます。敗北では成長後の最大HP／MPまで回復します。URL起動では自動保存し、再読み込みで再開します。別世界では主人公を引き継ぎ、世界の進行は別に保持します。「はじめから（セーブ初期化）」で確認後に初期状態へ戻ります。紹介画面とエディタの試遊は保存対象外です。攻撃技は戦闘中、習得済みの回復魔法は戦闘中とフィールドの「まほう」から使用できます。


## 初期技と序盤の習得通知

初期技ID 0〜2（強打・火の玉・癒し）はLv1で使えます。Lv3・Lv7・Lv8の魔法は既に登録されているため、初期技の習得レベルは変更しません。

| レベル | 累計経験値 | 新しく覚える魔法 |
|---|---:|---|
| 3 | 40 | 氷の矢（ID 3） |
| 7 | 330 | 大きな癒し（ID 4） |
| 8 | 470 | 雷撃（ID 5） |

通常の戦闘報酬で各境界を越えると、フィールドへ戻った際に「〇〇を覚えた！」と表示します。まとめてレベルが上がった場合も該当する魔法をすべて通知し、一度習得した魔法は再通知しません。`verify:progression` は実際の共通configを使い、境界直前の未習得・勝利後の習得・通知を検証します。上位魔法全体は [skills.md](./skills.md) を参照してください。

上位物理特技ID13〜16も初期の習得候補へ登録されています。累計470EXPで連撃（Lv8）、3,060EXPで渾身斬り（Lv18）、12,600EXPで疾風連斬（Lv36）、24,500EXPで天破斬（Lv50）を覚えます。段階習得と戦闘勝利後の通知を実configで検証します。

## 独立した魔力

主人公のLv1魔力は `encounters/player-config.json` の `stats.magic`（現在10）、1レベルごとの増加は `growthPerLevel.magic`（現在2）です。装備の `equipment.magic` を加算し、合計9999まで。攻撃力とは独立し、力の果実は魔力へ影響しません。省略された旧configの魔力・魔力成長・装備補正は0として読み込めます。

保存には経験値と装備IDがあるため、魔力は復元時に最新configから再計算します。保存形式とキーは変えず、既存の名前・成長・所持品・装備・世界の進行を維持します。「つよさ」に基礎魔力と装備補正、装備比較に魔力差、レベルアップ通知に魔力の増加を表示します。

現在の習得順はエスケープLv6、大きな癒しLv7、連撃Lv8、ゲート・ステルスLv10、ドレインLv12、マナバリアLv15、サンダーLv16、深い癒し・渾身斬りLv18、フロストLv22、命の光Lv35です。累計経験値表とLvごとの基礎能力成長は維持しています。威力と習得表の詳細は [魔法設定](./skills.md)。誘魔の髑髏輪は戦闘経験値だけ20%増加し、経験値の書には適用しません。


祝福の靴を装備すると、成功した1歩ごとに経験値を2得ます。歩行で上がったレベルにも全回復・能力増加・新技の通知を適用します。戦闘経験値は1.5倍を切り上げますが、歩行の2EXPと経験値の書は増幅しません。壁への空振り・方向変更・ワープは経験値を生みません。

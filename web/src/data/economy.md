# アイテム・装備・お店・所持金の編集

設定を保存し、ゲームページを再読み込みすると反映されます。IDの意味は変えず、新しい品には未使用のIDを付けてください。名前・価格・効果・装備能力はWeb共通の定義です。NFCにはこれまでどおりアイテムIDや敵IDだけを保存します。

## 装備を追加する

`item-catalog.json` の配列へ1件追加します。例えば未使用のID 31で鉄の剣を追加する場合：

```json
{
  "id": 31,
  "name": "鉄の剣",
  "description": "攻撃力＋12",
  "price": 150,
  "sellPrice": 75,
  "equipment": { "slot": "weapon", "attack": 12, "defense": 0, "requiredLevel": 5 }
}
```

装備部位 `slot` は `weapon`（武器）・`armor`（鎧）・`shield`（盾）・`accessory`（装飾品）・`head`（頭）の5種類。`attack`・`defense` は攻撃力・防御力、任意の `hp`・`mp` は最大HP・最大MP、`magic` は魔力の加算値です。各0〜9999の整数、HP・MP・魔力の省略時は0。各部位に1個ずつ装備し、成長後の基礎能力に足して戦闘・回復・バー表示へ反映します。合計能力は9999が上限です。交換した装備は所持品に残ります。装備中の1個も所持数に含め、最後の1個を売るには先に外す必要があります。同じ品を2個以上持っていれば余分な1個を売れます。戦闘中の装備変更はできません。

HP・MP装備の付け外し自体では回復しません。現在値が新しい上限を超えた場合だけ上限へ収めます。回復アイテム・魔法と敗北時の回復は装備込みの上限を使います。「つよさ」で最大HP・最大MPも基礎値と装備補正に分けて表示します。

IDは0〜255で重複不可。名前・説明、買値 `price`、売値 `sellPrice` は必須。価格は0〜999999の整数、売値は買値以下です。`effect` と `equipment` は同時に指定できません。両方省略すれば使用・装備できない所持品として扱います。追加した品はエディタのキラキラ／オブジェクトの一覧にも自動で出ます。

見本の装備はID 3＝木の剣、4＝銅の剣、5＝布の服、6＝革の鎧、7＝木の盾、8＝力のお守り。外見のキャラクター画像は変えず、数値と装備欄へ反映します。

王様の撃破報酬として、以下を各1個、1,500Gと900EXPを付与します。現在の成長表では、経験値0・レベル1からレベル10に到達します。王様を倒してフィールドへ戻る際、王冠・ローブ・剣を自動装備して、成長・装備後の最大HP・MPまで全回復します。初期状態から倒した場合はHP535／MP228です。王の杖は所持品に残り、「そうび」から剣と持ち替えられます。ほかの敵では王の装備の自動装備はしません。レベルアップ時はどの敵でも全回復します。

王冠＋ローブ＋王の剣または王の杖の3部位がそろうと、主人公の見た目を王様へ切り替えます。装備中の正面は既存の主人公ベースの王様、左右・後ろは主人公の64×64方向素材に銀髪・赤い服・小さな王冠とひげを反映した姿を使い、歩く方向に合わせて切り替えます。色と追加ピクセルの処理は `characters/king-directions.ts` に保存しています。1部位でも外す・別の装備へ交換すると、向いている方向を保ったまま元の主人公へ戻ります。画像は32×32のまま中央に描き、配置枠と足元の1×1マスの判定を維持します。

セットのIDは `royal-equipment.json` で編集できます。`headItemId` は頭、`armorItemId` は鎧、`weaponItemIds` は見た目を切り替える武器の一覧、`autoWeaponItemId` は撃破後に自動装備する武器（一覧内のID）です。3点すべてを所持し装備可能な場合だけ一括で装備・回復し、報酬や必要レベルを変更して装備できなくした場合は現在の装備を維持します。

| ID | 名前 | 部位 | 最大HP | 最大MP | 攻撃 | 防御 | 魔力 |
|---|---|---|---:|---:|---:|---:|---:|
| 9 | 王の王冠 | 頭 | +100 | +100 | +50 | +50 | 0 |
| 10 | 王のローブ | 鎧 | +200 | +50 | +50 | +120 | +40 |
| 11 | 王の杖 | 武器 | +100 | +200 | +30 | +50 | +180 |
| 12 | 王の剣 | 武器 | +150 | +50 | +200 | +50 | 0 |

全4点は装備Lv 1、仮の買値10,000G・売値500G。現在の店の商品へは自動追加しません。名前・数値・装備部位は `item-catalog.json`、報酬は `encounters/enemies/king.json` から変更できます。

## 回復アイテムを追加する

`equipment` の代わりに `effect` を指定します。

```json
{
  "id": 14,
  "name": "上やくそう",
  "description": "HPを40回復",
  "price": 30,
  "sellPrice": 15,
  "effect": { "type": "heal-hp", "amount": 40 }
}
```

`heal-hp` と `heal-mp` の `amount` は1〜9999の整数。最大値まで回復し、効果があったときだけ1個減ります。`cure-poison` は毒を治す効果で `amount` は不要です。毒でないときは使えません。初期設定はやくそう＝HP20回復・8G、どくけしそう＝毒解除・10G、まほうの水＝MP10回復・20G。おばけキノコの攻撃で毒を受けます。付与ターン直後の追加ダメージを除き、以後の敵ターン終了時に2ダメージを受けるので、どくけしそうなどで治療できます。特技／魔法で減ったMPはまほうの水で回復できます。満タン時は消費しません。技の追加は [特技・魔法の設定](./skills.md) を参照してください。

フィールドでは「どうぐ → 使う」。戦闘では「どうぐ → 品名」を選びます。成功すると主人公の行動を1ターン使い、「つづける」で敵のターンへ進みます。所持していない・使う必要がない場合は消費もターン進行もしません。

## お店の商品を追加する

`shop-catalog.json` の店員ごとの `items` にIDを足します。

```json
{ "merchant": "weapon-merchant", "name": "武器屋", "items": [3, 4, 31] }
```

店員は武器屋・防具屋・道具屋の3種類です。店員に話しかけ、挨拶を「つづける」で閉じると売買画面が出ます。自由文の挨拶も保持します。未設定の店員にも標準の挨拶を用意しています。「買う」は商品一覧から1個ずつ購入し、即時に所持金と所持品を更新します。お金が足りなければ購入しません。在庫数は現在無制限。「売る」はどの店でも所持品を1個ずつ売れます。店を閉じるまで歩行・エンカウントを止めます。

## 主人公の初期値と敵の報酬

`encounters/player-config.json` の `stats.hp`・`attack`・`defense` が基礎能力、`maxMp` が最大MP（0〜9999）、`initialGold` が開始時の所持金、`initialItems` が初期所持品です。見本はHP40・MP10・攻撃力10・防御力0・100G・所持品なし・装備なし。

```json
"initialItems": [{ "itemId": 0, "quantity": 3 }]
```

`encounters/enemies/` 内の敵JSONに `reward` を設定します。

```json
"reward": { "gold": 25, "experience": 20, "items": [{ "itemId": 0, "quantity": 2 }] }
```

ゴールドは0〜999999、数量は1〜9999。重複や存在しないアイテムIDは拒否します。未設定は `null`、報酬なしを明示するなら `{ "gold": 0, "items": [] }`。王様の現在の設定は上の4点・1,500G・900EXPです。撃破表示で報酬を知らせ、勝利確定時に一度だけ付与・保存します（保存しない試遊では結果画面を閉じる際）。逃走・敗北では付与しません。`king.ts` の報酬欄もこの共通JSONを参照します。

所持金・所持品・装備・残りHP／MPは同じプレイ中のステージ移動・再遭遇で引き継ぎます。敗北時は所持金が半減し、HP／MP全快・毒解除で復活します。装備・所持品・経験値は保持します。URL起動はブラウザへ自動保存し、同じ世界の再開と別世界への主人公の引き継ぎに対応します。確認付きのセーブ初期化で全世界の進行と主人公をリセットします。編集マップとURLデータ自体には結果を書き戻しません。装備の `requiredLevel`・報酬の `experience`・初期経験値と能力の成長は [レベルの設定方法](./progression.md) を参照してください。上の鉄の剣の例はレベル5から装備できます。


## 素材交換の追加・変更

正本は [exchange-recipes.json](./exchange-recipes.json)。レシピID・必要素材のIDと個数・完成品のIDと個数・手数料Gを設定します。品名・効果・能力は `item-catalog.json` から参照します。レシピと店の一覧はWeb共通設定のためNFC容量へ加算しません。

```json
{
  "id": 0,
  "ingredients": [{ "itemId": 13, "quantity": 2 }],
  "result": { "itemId": 19, "quantity": 1 },
  "gold": 4
}
```

各店の `shop-catalog.json` に `"recipes": [0, 1]` のようにレシピIDを指定すると、「買う」「売る」に加えて「素材交換」タブが出ます。省略／空配列では素材交換を表示しません。新しいレシピは未使用のID（0〜255）で配列へ追加し、扱う店の `recipes` へ登録してください。素材・完成品は既存のアイテムID、個数は1〜999999、手数料は0〜999999G（省略時0）。IDの重複・不明ID・空の素材・同じ素材の重複・不正な個数を拒否します。

| 店 | レシピID | 必要品 | 手数料 | 完成品 |
|---|---:|---|---:|---|
| 道具屋 | 0 | 若葉のしずく×2 | 4G | 上やくそう×1（HP50回復） |
| 道具屋 | 1 | 若葉のしずく×1・キノコの胞子×2 | 0G | どくけし丸×1（毒を治す） |
| 防具屋 | 2 | 森狼の毛皮×3・コウモリの羽×2 | 25G | 森狼のベスト×1（HP＋10・防御＋7） |
| 防具屋 | 3 | 森狼の毛皮×1・コウモリの羽×3 | 10G | 羽のお守り×1（MP＋8・防御＋2・魔力＋4） |
| 武器屋 | 4 | 銅の剣×1・岩のかけら×3 | 10G | 岩鉄の剣×1（攻撃＋12・防御＋1） |
| 武器屋 | 5 | 木の剣×1・岩のかけら×1・水晶の欠片×3 | 10G | 水晶の杖×1（MP＋15・攻撃＋2・魔力＋14） |

素材の行に所持数／必要数と手数料、完成品の効果・装備差分を表示します。「交換する」を押すと1回分を即時交換します。素材不足・お金不足・所持上限では何も消費しません。装備中の1個を使うには先に外します。同じ装備を複数持っていれば余分な分を使えます。強化元の剣は消費しますが、完成品は自動装備せず「そうび」から選びます。素材・完成品の入手履歴は図鑑へ残ります。各店の挨拶を閉じた後だけ交換でき、戦闘・フィールド・別の店ではその店のレシピを実行できません。

検証は `web/` で `npm run verify:exchanges`。全レシピ・効果・不足時の無消費・装備中の保護・実際の店員会話・拾った素材の二重加算防止・図鑑・リセットを確認します。タッチとキーボードでの表示・交換は `verify:editor`、両方とも `verify:all` に含まれます。

## 頭防具・強化の種・宿屋

防具屋には革の帽子（ID25・40G・防御+2・Lv1）、鉄の兜（ID26・120G・防御+6・Lv4）、魔導の三角帽子（ID27・150G・MP+10・攻撃+2・防御+3・魔力+6・Lv3）を登録しています。武器屋は水晶の杖も販売し、近くの宝箱は森狼のベスト・羽のお守り・岩鉄の剣などの探索報酬へ変更しています。

道具屋のちからの種（ID28・300G）は基礎攻撃力+1、いのちの木の実（ID29・300G）は基礎最大HP+5。フィールドの「どうぐ」で使用し、1個消費します。永久加算値はレベル・装備とは別に保存して別世界へ引き継ぎます。能力上限に達した場合は消費しません。種は戦闘の道具一覧には表示しません。

通常・巨大版の街の宿屋の主人（innkeeper）に話しかけ、はいを選ぶと15Gを消費し、装備込みHP／MP全回復・毒治療を行います。いいえでは消費せず閉じます。不足時は状態を変えません。

裏ボス報酬の星屑のオーブ（ID30）は装飾品でHP+100・MP+50・攻撃+30・防御+30・魔力+30。店頭では販売しません。

水晶の杖は攻撃+2・魔力+14、王の杖は攻撃+30・魔力+180で、剣との持ち替えは物理と魔法の得意分野を変えます。魔法攻撃は基礎威力＋魔力−敵防御（最低1）、回復魔法は基礎回復量＋floor(魔力×0.8)。店・所持品・装備一覧に説明と魔力差を表示します。装備変更そのものではHP・MPは回復しません。

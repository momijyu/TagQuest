# 敵と主人公の戦闘config

`enemies/` 内の敵ごとのJSONを変更して保存し、開発ページを再読み込みすると反映されます。魔王は [enemies/demon-lord.json](./enemies/demon-lord.json)、王様は [enemies/king.json](./enemies/king.json) です。[ゲーム設定の編集場所一覧](../README.md) に関連configもまとめています。公開版には再ビルド・公開が必要です。

`enemy-catalog.json` はJSONのファイル名を拡張子なしで並べた登録一覧です。WebとPythonは同じ登録一覧から読み込みます。新しい敵は `enemies/` にJSONを作り、ファイル名を登録一覧に追加します。既存の敵IDは変更せず、新しい敵には未使用のIDを使います。NFCには敵IDを保存し、HP・セリフ・行動・報酬はWeb共通の敵configから読み込みます。王様・草原／森向け3体・魔王・洞窟向け3体・橋の子分・はぐれクリスタル・古代の虚無神・虚無の回廊の3体（計14種類）を登録しています。

| 項目 | 意味 |
|---|---|
| `id` | NFCが指定する敵ID（0〜255、重複不可） |
| `name` | 敵の名前 |
| `characterId` | フィールド上のキャラクター識別子 |
| `battleImage` | 戦闘専用素材ID。草原・森・洞窟の6体と魔王はドット版。王様は省略して既存素材を使用 |
| `background` | `castle`・`grassland`・`forest`・`cave`。省略時は城 |
| `stats.hp` | 最大HP（1〜9999） |
| `stats.attack` | 攻撃力（0〜9999） |
| `stats.defense` | 防御力（0〜9999） |
| `canEscape` | 逃走可否。省略時true |
| `canEscapeBeforeAttacked` | trueなら未攻撃の間だけ逃走を許可。王様はtrue、攻撃後はcanEscape:falseに従う |
| `firstAttackedMessage` | 初めて攻撃された後の敵ターンに言うセリフ。省略可 |
| `patterns.beforeAttacked` | 一度も攻撃されていないときの行動リスト |
| `patterns.afterAttacked` | 一度でも攻撃された後の行動リスト |

行動リストは上から順番に使い、最後まで進むと先頭へ戻ります。それぞれ1〜64件を設定します。攻撃されると怒った側のリストを先頭から開始します。

## 草原・森のモンスター

| 敵ID | 名前 | 戦闘背景 | HP | 攻撃 | 防御 | 経験値 | G |
|---|---|---|---:|---:|---:|---:|---:|
| 1 | リーフジェル | 草原 | 18 | 4 | 0 | 16 | 4 |
| 2 | おばけキノコ | 森 | 28 | 6 | 1 | 28 | 8 |
| 3 | 森オオカミ | 森 | 38 | 8 | 2 | 44 | 12 |

すべて仮の数値で、このJSONから変更できます。リーフジェルは体当たり→葉っぱ飛ばし、キノコは根っこ→かさの攻撃、オオカミはかみつき→爪の攻撃を繰り返します。王様と異なり、攻撃していない場合も敵ターンで攻撃します。各モンスターの前後の行動リストは同じ設定です。攻撃パターンの使い分けは既存の `beforeAttacked`／`afterAttacked` で編集できます。オオカミは強めなので、魔法・回復や装備も使う想定です。固有素材（ID 13〜15）を各1個落とします。ジェルはやくそう、キノコはどくけしそうも1個落とします。

エディタでステージを選び、「エンカウント」の「出現する敵」から選択して、確率と有効／無効を反映してください。設定したステージで歩くと遭遇します。通常モンスターは撃破後も再遭遇し、戦闘ごとに経験値とゴールドを得られます。フィールドへのオブジェクト配置やドット絵は不要です。1種類の指定に加え、複数の敵IDと出現割合からの抽選にも対応します。

戦闘のドット素材は `enemy-pixels.ts` の `enemyPixelSprites` に登録しています。ジェルとキノコは48×48・12色、オオカミは64×48・16色です。パレットと整数座標の描画を編集できます。ゲームではピクセル配列を整数倍率で描き、画像の補間は行いません。原寸PNGと拡大見本は `art/enemies/pixels/` にあり、`web/` の `npm run export:enemy-pixels` でコードから書き出せます。

新しいドット素材を追加するときは `enemy-illustration-ids.json` に新しい素材IDを加え、`enemyPixelSprites` に同じキーで `PixelSprite` を登録し、敵JSONの `battleImage` にIDを指定します。`characterId` にも敵ごとの別の識別子を指定します。通常モンスターは王様の特別ルールを使わないため `king` 以外にしてください。戦闘専用素材はフィールドのNPC一覧へ追加する必要はありません。魔王は立ち姿も持ち、NPC一覧にも登録しています。素材と背景はWeb共通で、NFCには既存どおり敵IDのみ保存します。

紹介画面の「モンスター図鑑」は草原・森の魔物3種、洞窟の魔物4種、ボス・強敵7種へ分類し、種類数・ドット絵・HP／攻撃／防御を表示します。王様は既存のキャラクター素材を使い、異次元の通常魔物3種は強敵の分類へ含めます。元の背景透過PNGは `web/src/assets/enemies/` に保持し、各素材の「参考イラスト」を開くと元の絵を見られます。原案の生成方法とプロンプトは [素材の生成記録](../../../../art/enemies/prompts.md)、ドット版の仕様は [ドット素材の記録](../../../../art/enemies/pixels/README.md) に保存しています。

## 行動と戦闘の設定

```json
{ "type": "say", "text": "よく来たのう、勇者よ。" }
```

`say` はセリフだけの敵ターンです。HPは減りません。本文は敵の頭上の吹き出しにも表示します。

```json
{ "type": "attack", "text": "王様は杖を振り下ろした！", "power": 1 }
```

`attack` はメッセージと攻撃です。`power` は0より大きく10以下の攻撃倍率で、1.5なら通常の1.5倍。`text` は改行を含めて入力でき、HTMLとして解釈しません。王様の初期設定はHP30・攻撃力6・防御力0。攻撃される前はセリフ2件、攻撃後は杖（1倍）→光（1.5倍）の順で繰り返します。初回の反撃には「何をするんじゃ！！！」を先に表示します。

攻撃中に話すセリフは任意の `speech` に指定します。`text` は行動説明、`speech` は頭上の吹き出し用です。初回の反応があるターンは `firstAttackedMessage` → `speech` の順で吹き出しに表示します。`say.text`・`speech`・初回の反応は下部のログにも残し、読み上げ通知はログ側だけで行います。長い本文は吹き出し内でスクロールできます。

```json
{ "type": "attack", "text": "王様は杖から光を放った！", "speech": "無礼者め！", "power": 1.5 }
```

主人公の設定は `player-config.json` です。初期値はHP40・攻撃力10・防御力0。`guardMultiplier: 0.5` は「ぼうぎょ」した直後の敵ターンだけダメージを半分にします。倍率は0より大きく1以下。

現在のダメージ式は、主人公の攻撃が `max(1, 攻撃力−敵の防御力)`、敵の攻撃が `max(1, floor(攻撃力×power)−主人公の防御力)`。防御時はこの値に `guardMultiplier` を掛け、小数点以下を切り捨てて最低1とします。0攻撃力や高い防御力でも最低1ダメージです。装備の攻撃力／防御力を反映し、回復アイテムの使用にも対応します。特技／攻撃魔法／回復魔法の使用とMP消費にも対応します。[技の設定方法](../skills.md) を参照してください。乱数・命中・会心・属性はまだありません。

「つづける」で主人公の行動→敵の行動→次のコマンドへ進みます。敵を倒したときは敵のターンを行いません。行動確定後はEscapeで攻撃や敵のターンを取り消せません。どうぐ・スキルの一覧から戻る操作ではターンを使いません。1対1なので通常攻撃・攻撃スキルは選択と同時に発動します。回復アイテムを使えた場合だけ1個と1ターンを消費します。`canEscape` の省略または `true` なら逃走できます。魔王と攻撃後の王様は `false` に従い、「にげる」を選ぶと「この戦いからは逃げられない！」と表示してコマンド選択に留まります。ターンやHP・MPは消費せず、他のコマンドを選べます。開戦前のNPC会話は「やめる」で閉じられます。

主人公の残りHPと王様を攻撃した状態は同じプレイ中に引き継ぎ、敗北後の再戦や、逃走可能に変更した設定で逃走して再遭遇しても、王様は怒ったままです。敵HPは再遭遇時に最大へ戻ります。主人公が倒れると「復活する」で所持金を半減（残額は端数切り捨て）し、失ったGと残額を表示して、HP・MPを全快、毒を解除し、現在のステージの開始位置へ戻ります。開始位置がないステージではプレイを始めたステージへ戻ります。所持品・装備・レベル・経験値・図鑑・取得済み状態・撃破済み状態は保ちます。減額率は `player-config.json` の `defeatGoldLossPercent`（0〜100、省略時50）から設定し、0で無損失、100で全額損失にできます。復活を一度確定した後、通知の再表示で重複減額しません。「最初から」／再読み込みで全状態を初期化します。

勝利報酬は敵ごとの `reward` に `{ "gold": 25, "experience": 20, "items": [{ "itemId": 0, "quantity": 2 }] }` の形で設定します。撃破してフィールドへ戻るときに一度だけ付与し、逃走・敗北では付与しません。`experience` は省略時0です。王様は1,500G・900EXP・王の王冠（ID 9）／王のローブ（10）／王の杖（11）／王の剣（12）各1個を付与します。今の成長表では初期状態からレベル10に到達します。`king.ts` の報酬欄もこのJSONを参照します。主人公の `maxMp`・`initialGold`・`initialItems`、装備・商品・価格の詳しい設定例は [経済・装備の編集方法](../economy.md) を参照してください。経験値・成長表・技の習得レベル・装備制限は [レベルの設定方法](../progression.md) を参照してください。主人公の `stats` と `maxMp` はレベル1の基礎値、開始レベルは `initialExperience` から計算します。configの内容はNFC容量に加算しません。

王様の勝利後は報酬・成長を反映してから、王冠・ローブ・剣を自動装備し、HP・MPを装備込みの上限まで回復します。3点を装備している間は主人公が王様へ変わり、歩く方向に合わせて正面・左右・後ろ姿を切り替えます。剣から王の杖へ持ち替えても王様の見た目を維持します。通常の敵の勝利・逃走では自動装備・回復を行いません。セットのIDと自動装備の武器は `../royal-equipment.json` で編集できます。

## 魔王の仮設定

編集ファイルは [enemies/demon-lord.json](./enemies/demon-lord.json)。敵ID 4、素材ID `demon-lord`、背景 `castle`。HP360・攻撃36・防御12で、剣（power 1）と闇の炎（power 1.4）を繰り返します。これらは確認用の仮値です。報酬は0G・0EXP・アイテムなしにし、同じJSONの `reward` から追加できます。NFCに保存するステージ設定から指定し、魔王城の見本には一度限り・勝利でGAME CLEARの戦闘イベント付きNPCを配置しています。確率エンカウントでは撃破後も再遭遇します。ボス戦は配置したNPCにエディタで「話しかけて戦闘」を設定し、勝利時の消失・GAME CLEARも指定します。現在の魔王は逃走不可で、敗北では再戦できます。

正本は `../characters/demon-lord.ts`、戦闘用64×56・立ち姿32×32の16色です。エディタのNPCとしても置けますが、会話設定とステージの遭遇設定は別です。[魔王の記録](../../../../art/demon-lord/README.md) を参照してください。

## 任意の敵への王の装備の攻撃倍率設定

レベル上限99への拡張に合わせ、魔王は以前の3倍のHP360・攻撃36・防御12へ調整しています。魔王の攻撃100倍と主人公の王装備の攻撃ボーナス低下は両方解除済みです。必要なら任意の敵configへ次を設定できます。

```json
"royalEquipmentAttack": { "multiplier": 100, "match": "any" }
```

`match: "any"` は王冠・ローブ・杖・剣のどれかを装備している場合、`"set"` は王様の見た目になる3点セットの場合に発動します。単に所持しているだけでは発動しません。装備のIDは `../royal-equipment.json` を共通で使います。判定は戦闘開始時に行い、魔王の基礎攻撃力へ倍率を適用してから、各攻撃のpower・主人公の防御力・ぼうぎょを計算します。未設定の敵には影響しません。倍率は1〜1000で編集でき、王の装備の能力値は維持します。

## 任意の敵への王の装備の攻撃ボーナス低下設定

`royalEquipmentPlayerAttackMultiplier` は省略時に通常性能になります。現在の魔王configではこの項目を削除しており、Lv10・王冠＋ローブ＋剣の攻撃力328をそのまま使います。敵の攻撃100倍も設定しません。

任意の敵に `"royalEquipmentPlayerAttackMultiplier": 0` を設定すると、その戦闘で王の装備の攻撃ボーナスだけを無効にできます。倍率は0〜1で、0.1は10%、1は通常性能です。レベルによる基礎攻撃力・通常装備・HP・MP・防御・固定ダメージ魔法は維持します。装備ボーナスを合計してから倍率を掛けて切り捨て、通常装備と基礎攻撃力を加算して上限9999を適用します。これらの共通設定はNFC容量へ加算しません。

複数のランダム敵は、NFC用の各マップのencounterに `enemies: [{enemyId: 1, weight: 60}, {enemyId: 2, weight: 30}, {enemyId: 3, weight: 10}]` を追加する。rateは1歩ごとの遭遇率、weightは遭遇した場合の敵の比率。エディタの「複数の敵（出現割合）」でも編集できる。候補が3種類なら出現設定は9B（単一指定は2B）。既存の編集データは自動変更しない。充実版の見本の出現表は `compiler/maps/adventure-encounters.json` で管理する。

魔王の `royalEquipmentWarning` は王の装備への攻撃倍率が発動する場合のヒント文。NPCの戦闘前会話と開戦メッセージに現在の装備に合わせて表示する。省略時は表示しない。現在の魔王configでは省略しており、見本の会話にも攻略ヒントを含めない。王の装備を所持しているだけの場合や、すべて外している場合は表示しない。現在の魔王には攻撃100倍・王の攻撃ボーナス低下も設定しない。


## 毒攻撃と逃走可否

攻撃行動に `"inflictPoison": true` を追加すると、攻撃を受けて生存した主人公に毒を付与します。省略／falseは通常攻撃です。おばけキノコの2番目の「大きなかさを振り回した！」は、攻撃前・攻撃後どちらのパターンでも確定で毒を付与します。新たに付与されたターンに「ゆうしゃは毒を受けた！」を表示しますが、そのターンは毒ダメージを受けません。敵ターン開始時から毒状態だった場合に、終了時に2HPの毒ダメージを受けます。毒を持ち越して開戦した場合は最初の敵ターンから減り、毒攻撃を再び受けても継続ダメージを延期しません。毒ダメージでHP0になれば敗北します。勝利時は追加ダメージを与えません。

毒は歩行・ステージ移動・逃走後も持ち越しますが、歩行だけではHPを減らしません。戦闘・フィールドの状態欄に「毒」を表示します。「どくけしそう」（ID 1）はどちらでも治療でき、毒でないときは個数を消費しません。戦闘での使用は1ターンを使い、後の毒攻撃では再び毒になります。敗北からの復活と「最初から」では毒を解除します。

敵JSONの最上位に `"canEscape": false` を設定すると逃走不可、省略／trueは逃走可です。王様・魔王はfalseですが、王様は `canEscapeBeforeAttacked: true` により未攻撃の間だけ逃げられます。逃走不可の場合は警告のみでコマンド選択を維持し、ターンを消費しません。NPCの開戦前の会話は「戦う」「やめる」で選択でき、Escapeキーでも閉じられます。戦う前ならメニューへ戻って準備できます。これらはWebの敵共通設定で、NFC形式や容量を増やしません。

GAME CLEARのメッセージを閉じた後も歩行・会話・買い物・ステージ移動が可能です。撃破済みNPCは消えたままで、お祝いと「最初から」の案内を常時表示します。通常の敵との戦闘も継続でき、以後の勝利でクリアメッセージを繰り返し表示しません。


## 洞窟のモンスターと見本の出現表

| 敵ID | JSON | 名前 | HP | 攻撃 | 防御 | EXP | G | 固有ドロップ |
|---|---|---|---:|---:|---:|---:|---:|---|
| 5 | `enemies/cave-bat.json` | 洞窟コウモリ | 24 | 6 | 1 | 24 | 7 | コウモリの羽（16） |
| 6 | `enemies/rock-hermit.json` | 岩ヤドカリ | 48 | 9 | 5 | 52 | 14 | 岩のかけら（17） |
| 7 | `enemies/crystal-lizard.json` | 水晶トカゲ | 60 | 12 | 4 | 76 | 22 | 水晶の欠片（18） |

洞窟背景は `cave`。ドット素材の正本は `cave-enemy-pixels.ts`、全て64×48で戦闘時は2倍に描画します。コウモリはやくそう、トカゲはまほうの水も落とします。ドロップは現在確定取得で、`reward.items` のID・個数を編集できます。固有素材の効果・価格は `../item-catalog.json`。図鑑は初めて入手した時に記録され、売却・消費しても現在の冒険中の履歴を残します。

充実版の見本では森12%（ID 1:2:3＝5:3:2）、洞窟14%（5:6:7＝5:3:2）、城の隠し王様は0.1%。小型城＋街の容量検証用データとは別です。`rate` は0〜100の0.01%刻みで、整数なら従来の保存形式、小数ならTQ v15（単一6B、複数 `4 + 2×候補数` B）を使います。戦闘イベントの件数は別に1Bあります。

レベル上限99に合わせ、王様以外の敵の `reward.experience` を以前の2倍へ調整しました。森のリーフジェル16EXP／おばけキノコ28EXP／森オオカミ44EXP、洞窟は上表の24／52／76EXPです。王様は900EXPを維持し、魔王は元が0EXPのため0のままです。ゴールド・ドロップ・通常敵の能力・出現率は変更しません。報酬と敵能力はWeb共通設定なので、既存のNFCリンクでも公開更新後に反映され、NFCのデータ長は変わりません。

王様戦は、通常攻撃や攻撃魔法を使う前なら「にげる」で離れられます。防御・回復は怒りを誘発しません。一度攻撃すると、その冒険中は怒りが保持され、再遭遇でも逃走不可です。逃走を試してもターンは消費しません。魔王戦は引き続き逃走不可ですが、王の装備への特殊補正も危険警告もありません。

戦闘の「どうぐ」は効果を持つ所持消費アイテムのみを名前・個数・説明付きで表示します。装備・素材を表示せず、使える道具がない場合は決定キーでもコマンドへ戻れます。

NFC向け6マップの小型版だけは、城の王様の遭遇率を1%の整数へ変更し、遭遇設定を6Bから2Bに縮めました。通常版・巨大版と初期城＋街の0.1%は維持します。森・洞窟の確率と3種類ずつの出現表は変更しません。


## 巨大版の橋の子分

敵ID8「魔王の子分」は [enemies/demon-guard.json](./enemies/demon-guard.json) で管理します。HP90・攻撃14・防御4、逃走可能。剣（1倍）と盾の体当たり（1.3倍）の2行動を順に使います。報酬は180G・180EXP・上やくそう2個・まほうの水1個です。既存の敵configの値は変更しません。

巨大版の辺境の中央橋へNPC demon-guardとbattleEvent（enemyId8、once:true、clear:false）を置き、勝利時だけ消して橋の近道を開きます。敗北／逃走では残り、リセットで復元します。東の橋を使えば戦わずに通れるので、本編クリア条件ではありません。NPCは1×2の配置枠・足元1×1の通行判定、32×32の立ち姿です。素材は [demon-guard.ts](../characters/demon-guard.ts) の既存魔王ドットを基にした青マント・鉄兜の16色版、戦闘は64×56です。

## 希少敵・裏ボスの行動

- はぐれクリスタル（ID10）：HP8・攻撃8・防御50。各敵ターンに50%で逃走し、失敗時は通常攻撃。撃破報酬は250EXP・100G、敵が逃げた場合は報酬を付与しません。通常／巨大版の洞窟の出現表にweight5で登録しています。
- 古代の虚無神（ID11）：HP1200・攻撃55・防御25・魔力55、虚無の爪痕1.4倍→虚無の波動1.2倍→深淵の闇60回復。1ターンに2行動を順番に実行します。逃走不可。クリア後の虚無の異空間に一度きりのNPCイベントを用意し、星屑のオーブ・称号・1000G・1000EXPを得ます。

新行動は `{ "type": "escape", "text": "...", "chance": 0.5 }`（chanceは0〜1）と `{ "type": "heal", "text": "...", "amount": 80 }`。再生は敵最大HPまで、逃走の失敗は通常倍率の攻撃です。戦闘終了後は敵の種類・結果を問わず6歩の遭遇保護を設けます。

出現設定は `game/postgame.ts`。率6%、割合45:35:20で、戦闘後の6歩保護を維持します。ステージの元データや小型版のURLにこれらを加算しません。登録一覧と能力はWeb共通configです。

`actionsPerTurn` は1〜4の整数、省略時1。複数行動は同じリストを続けて読み、最後から先頭へ戻ります。主人公の死亡または敵の逃走で後続の行動を中止し、毒ダメージは1ターン1回、初回付与ターンは発生しません。防御コマンドはそのターンの全攻撃に有効です。

`magic-attack` は `{ "type": "magic-attack", "text": "虚無の波動！", "power": 1.2 }`。ダメージは敵の魔力×powerを切り捨て、最低1、物理防御は引きません。防御コマンドで軽減できます。物理攻撃は従来どおり敵攻撃力×倍率−主人公防御を使用します。

任意の `victoryMessage` は撃破ログの報酬後へ追加します。虚無神は「古代の虚無神を打ち倒し、世界の真の覇者となった！」。次のレベルまでのEXPは勝利ログの末尾へ表示します。

- `slow`: `{type:"slow", text:"糸の拘束！", turns:2}`。行動順の素早さステータスは未導入のため、次の2回の攻撃・特技／魔法・防御の試行時に25%で動けずターンを消費する形です。失敗時にMPは消費せず、道具は影響を受けません。戦闘終了で解除。

- `family:"dragon"` の敵には、装備の `dragonMultiplier` が通常攻撃と物理特技へ適用されます。魔法へは適用しません。

# 特技・魔法の追加

`skill-catalog.json` に技を追加し、`encounters/player-config.json` の `skills` にそのIDを入れると、主人公が習得レベルに達したときに使用できます。保存後にページを再読み込みしてください。技IDは0〜255で、アイテムIDとは別の一覧です。重複や知らない習得IDは拒否します。

例えばID 3の魔法を追加する場合：

```json
{
  "id": 3,
  "name": "氷の矢",
  "kind": "spell",
  "description": "敵に16ダメージ",
  "learnLevel": 3,
  "mpCost": 4,
  "effect": { "type": "magic-damage", "amount": 16 }
}
```

主人公の習得欄：

```json
"skills": [0, 1, 2, 3]
```

| 項目 | 設定 |
|---|---|
| `id` | 未使用の0〜255の整数 |
| `name` / `description` | 技名と効果の説明 |
| `kind` | `technique`＝特技、`spell`＝魔法 |
| `mpCost` | 消費MP、0〜9999の整数 |
| `learnLevel` | 習得レベル、1〜99の整数。省略時1 |
| `effect.type` | `physical-damage`・`magic-damage`・`heal-hp` |

`physical-damage` は `power`（0より大きく10以下の倍率）を指定し、装備を反映した主人公の攻撃力から `max(1, floor(攻撃力×power)−敵の防御力)` で計算します。`magic-damage` は `amount`（1〜9999）の固定ダメージで、敵の防御力を引きません。`heal-hp` は `amount` の分だけ自分のHPを最大値まで回復します。属性・命中・複数対象・状態異常などは今後設計します。

見本は強打＝特技・MP2・攻撃力1.5倍、火の玉＝魔法・MP3・12ダメージ、癒し＝魔法・MP3・HP20回復。主人公はこの3つを最初から習得します。`skills: []` なら未習得です。

戦闘コマンドの「とくぎ」「まほう」から選択します。攻撃技は技→敵の順に確定します。「もどる」／Escapeで技一覧へ戻ってもMPを消費しません。回復魔法は自分へ使います。成功したときだけMPと1ターンを消費し、「つづける」で敵ターンへ進みます。MP不足の技は選べず、未習得やHP全快の回復もMP・ターンを使いません。技で敵を倒した場合も通常攻撃と同じ勝利・報酬・王様の消失を使い、反撃はありません。攻撃技／魔法は王様の怒りを発生させますが、回復魔法は発生させません。

技一覧が空、またはすべてMP不足で選択不可の場合は、E・Enter・Spaceでコマンド選択へ戻ります。MPやターンは消費しません。

残りMPは逃走・ステージ移動・再遭遇で保持し、まほうの水で回復できます。敗北の復活と「最初から」で全快します。HP／MPは歩行・戦闘・メニューでバーと補助の数値を表示します。MP上限0でもバーは空で表示します。「つよさ」には習得した技とMPコストも表示します。フィールドの「どうぐ」内の「まほう」タブでは、習得済みの回復魔法を使えます。癒しはMP3でHPを最大20回復します。HP全快・MP不足・未習得の場合は使用できず、MPを消費しません。攻撃技は戦闘中だけ使えます。

技定義と習得欄はWeb側の共通設定です。NFC形式・マップのデータ長は変えず、見本の206Bを維持します。レベルによる自動習得は [成長の設定方法](./progression.md) を参照してください。習得イベント・NFCでの習得指定は別途設計します。

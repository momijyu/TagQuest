# 特技・魔法の設定

`skill-catalog.json` に定義を追加し、`encounters/player-config.json` の `skills` にIDを登録すると指定レベルで習得します。既存ID0〜23は維持し、新規追加には未使用の24以降を使います。IDは0〜255、習得レベルは1〜99。呪文・技の名前は単一名称にし、ASCII／全角の括弧を含む名前は拒否します。未習得は「???」で表示します。

```json
{
  "id": 3,
  "name": "氷の矢",
  "kind": "spell",
  "description": "鋭く尖った冷気の矢を撃ち放ち、敵の急所を射抜く氷結魔法。",
  "learnLevel": 3,
  "mpCost": 4,
  "effect": { "type": "magic-damage", "amount": 18, "magicScale": 0.4 }
}
```

## 威力・回復の計算

`amountRange` を指定した技は、その `min`〜`max` の整数を等確率で抽選します。省略した技は `floor(amount × (0.85 + random() × 0.3))` の基礎値を使います。どちらも成功した発動ごとに1回だけ抽選し、描画や失敗時には抽選しません。回復魔法は指定範囲を使い、攻撃魔法は基礎値±15%です。

- 攻撃魔法：`max(1, 基礎値 + floor(装備込み魔力 × magicScale) − 敵防御)`。
- 回復魔法：`基礎値 + floor(装備込み魔力 × magicScale)`を現在のHP不足分まで回復。戦闘とフィールドで共通です。
- 物理特技：`max(1, floor(装備込み攻撃力 × power × 剛力補正 × 会心補正 × 特効) − 敵防御)`。

`magicScale` は0〜10。旧定義で省略した場合は攻撃1.0／回復0.8。`amount`・`amountRange.min/max` は1〜9999、`min <= max`。`power` は0より大きく10以下です。説明文は情景を表す文にし、数値の基礎威力をゲーム画面に表示しません。

## 特殊効果・操作

- サンダーは `ignoreDefense:true` で敵防御を0として計算。ドレインの `drainFraction:0.5` は実際に削った敵HPの半分を回復し、撃破時も適用。フロストの `freeze:true` は生存敵の次の敵ターン全体を止め、複数行動・連撃にも有効。既存の毒・呪いの侵食は止まりません。
- マナバリアは `turns:3, reduction:0.5`。発動直後を含む3敵ターンの魔法を半減し、防御と重複します。物理・毒・呪いは軽減せず、再使用で3ターンへ更新、戦闘終了で解除。
- ゲートは足元に光の魔方陣を表示し、メニューと街の入口付近から無料で戻れます。設置はMP5、再設置で上書き。`tagquest.return-portal`と主人公セーブに世界別保存し、別世界や通行不能な位置への復帰を防ぎます。初期化で門も消します。
- エスケープは実際に入ってきた位置へ戻ります。入口履歴がない場合は外への出口→他出口→開始位置を使います。街やお城では使えず、帰り先がなければMPを消費しません。移動後は通常遭遇を6歩保護します。
- ステルスは通常遭遇を40歩防止。成功した歩行と出口通過を数え、壁への空振りは数えません。残り歩数を保存・表示、再使用で40歩へ更新し、敗北で解除。NPCボス戦は防がず、誘魔の呪いでも保護を短縮しません。

フィールドの「まほう」は回復・ゲート・エスケープ・ステルス、戦闘は攻撃・回復・マナバリアを表示。1対1の攻撃は選択と同時に発動し、ターンの確認で敵が行動します。MP不足・全快時の回復・対象外の脱出はMPや乱数を消費しません。移動成功時はメニューを閉じて移動先を表示します。

装備の `mpCostReduction` を部位ごとに合算し、呪文は `max(1, 通常MP − 合計軽減)`。物理特技は元のMPです。一覧に「MP 1（通常3）」、つよさに合計値を表示します。技と魔力の設定はWeb共通で、小型版の全12ファイルは不変（302B／439B URL／444B NDEF）。[装備と戦闘アイテム](./economy.md)・[成長](./progression.md)も参照してください。

# 特技・魔法の追加

`skill-catalog.json` に技を追加し、`encounters/player-config.json` の `skills` にそのIDを入れると、主人公が習得レベルに達したときに使用できます。保存後にページを再読み込みしてください。技IDは0〜255で、アイテムIDとは別の一覧です。重複や知らない習得IDは拒否します。

既存のID 3「氷の矢」の設定例（新しく追加する場合は未使用のID 17以降を使います）：

```json
{
  "id": 3,
  "name": "氷の矢",
  "kind": "spell",
  "description": "魔法で攻撃（基礎18）、魔力で威力が伸びる",
  "learnLevel": 3,
  "mpCost": 4,
  "effect": { "type": "magic-damage", "amount": 18 }
}
```

主人公の習得欄の抜粋（現在はID 0〜16を登録）：

```json
"skills": [0, 1, 2, 3]
```

| 項目 | 設定 |
|---|---|
| `id` | 未使用の0〜255の整数 |
| `name` / `description` | 技名と効果の説明 |
| `kind` | `technique`＝特技、`spell`＝魔法 |
| `mpCost` | 消費MP、0〜9999の整数 |
| `learnLevel` | 習得レベル、1〜99の整数。省略時1 |
| `effect.type` | `physical-damage`・`magic-damage`・`heal-hp` |

`physical-damage` は `power`（0より大きく10以下の倍率）を指定し、装備を反映した主人公の攻撃力から `max(1, floor(攻撃力×power)−敵の防御力)` で計算します。`magic-damage` は `max(1, amount + floor(装備込み魔力×1.0) − 敵の防御力)` で計算します。`heal-hp` は `amount + floor(装備込み魔力×0.8)` を回復量の上限として、自分の最大HPまで回復します。属性・命中・複数対象・状態異常などは今後設計します。

強打＝特技・MP2・攻撃力1.5倍、火の玉＝魔法・MP3・基礎威力12、癒し＝魔法・MP3・基礎回復量20。主人公はこの3つを最初から習得し、以下の追加魔法をレベルアップで覚えます。攻撃魔法はレベル・装備の魔力で伸び、属性・複数対象は未実装です。回復魔法はフィールドでも使えます。`skills: []` なら未習得です。

戦闘コマンドの「とくぎ」「まほう」から選択します。1対1のため攻撃技は選択と同時に発動します。選ぶ前なら「もどる」／Escapeでコマンドへ戻れます。確定した技は取り消せません。回復魔法は自分へ使います。成功したときだけMPと1ターンを消費し、「つづける」で敵ターンへ進みます。MP不足の技は選べず、未習得やHP全快の回復もMP・ターンを使いません。技で敵を倒した場合も通常攻撃と同じ勝利・報酬・王様の消失を使い、反撃はありません。攻撃技／魔法は王様の怒りを発生させますが、回復魔法は発生させません。

技一覧が空、またはすべてMP不足で選択不可の場合は、E・Enter・Spaceでコマンド選択へ戻ります。MPやターンは消費しません。

残りMPは逃走・ステージ移動・再遭遇で保持し、まほうの水で回復できます。敗北の復活と「最初から」で全快します。HP／MPは歩行・戦闘・メニューでバーと補助の数値を表示します。MP上限0でもバーは空で表示します。「つよさ」には習得済みの技の名前・MPコスト・効果説明を表示します。未習得の技は「???」とし、名前・必要MP・効果・習得レベルを隠します。フィールドメニューの「まほう」タブでは、習得済みの回復魔法を使えます。癒しはMP3で基礎20＋魔力×0.8（切り捨て）を最大回復量に使います。HP全快・MP不足・未習得の場合は使用できず、MPを消費しません。攻撃技は戦闘中だけ使えます。

技定義と習得欄はWeb側の共通設定です。NFC形式・マップのデータ長は変えず、見本の206Bを維持します。レベルによる自動習得は [成長の設定方法](./progression.md) を参照してください。習得イベント・NFCでの習得指定は別途設計します。


## 段階習得する物理特技

初期の強打（ID0）はLv1・MP2・攻撃力1.5倍のままです。既存ID0〜12を変えず、次の4種類を末尾に登録しました。

| ID | 特技 | 習得Lv | MP | 基礎威力／基礎回復量 |
|---|---|---:|---:|---|
| 13 | 連撃 | 6 | 5 | 攻撃力の2倍 |
| 14 | 渾身斬り | 18 | 10 | 攻撃力の2.5倍 |
| 15 | 疾風連斬 | 36 | 18 | 攻撃力の3倍 |
| 16 | 天破斬 | 50 | 28 | 攻撃力の4倍 |

`kind: "technique"`、`effect: { "type": "physical-damage", "power": 倍率 }`で定義します。ダメージは装備込み攻撃力×倍率を切り捨てて敵の防御力を引き、最低1です。連撃の名前でも処理上は合計ダメージを1回の行動で与えます。フィールドでは使用できません。習得・効果・MP消費はWeb共通configから読み込み、NFCに技データを追加しません。

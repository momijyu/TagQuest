# 成長・保存・クリア後の冒険

## 遊び方と保存

データ入りURLで遊ぶと、`tagquest.play-save.v1` に自動保存します。同じ世界では前回の位置・宝箱・撃破・会話・クリア状態を復元し、違う世界では保存した主人公を引き継いで最初の位置から始めます。主人公の名前・経験値・レベル・HP／MP・所持金・5部位の装備・所持品・毒・果実による強化・図鑑を保持します。

「メニュー → つよさ → 名前変更」で名前を1〜20文字に変更できます。「はじめから（セーブ初期化）」は確認後に主人公と全世界の保存を消し、現在の世界を初期状態へ戻します。紹介画面とエディタ内の試遊は自動保存を使いません。

保存は同じブラウザ・同じ公開先の範囲です。別端末・別ドメインには自動で移りません。世界を編集してURLが変わると新しい世界として扱い、主人公は引き継ぎます。保存中の戦闘そのものは復元せず、消費したHP／MP・道具を保ってフィールドから再開します。勝利表示中に閉じても報酬を保存し、敗北表示中に閉じても再開時に一度だけ所持金半減と全回復を適用します。世界の進行を読み込めない場合は、主人公と他世界を保持してその世界だけ開始地点へ戻します。保存全体を読めない場合は直前のバックアップからの復元を試し、それも使えなければ初期状態で起動します。修復前の原本は退避し、保存失敗も画面に表示します。

## 成長と魔法（追加改修反映）

Lv2・3・4の累計必要経験値を15・40・80へ緩和。レベルアップはHP／MP全回復で、毒は保持します。勝利ログで能力増加・次までのEXP、フィールドで現在の目的・次までのEXPを表示します。最大Lv99と段階習得を維持します。

追加指示に従い、独立した魔力を導入しました。初期10・毎Lv+2で、装備の魔力補正を加算します。現在は呪文ごとの基礎乱数と魔力係数を使います。物理攻撃力とは独立しています。

- 攻撃魔法：`max(1, floor(基礎威力 × 乱数0.85〜1.15) + floor(装備込み魔力 × 呪文ごとの係数) - 敵防御力)`。防御無視の呪文は敵防御を引きません。
- 回復魔法：基礎範囲内の整数乱数＋装備込み魔力×呪文ごとの係数を切り捨て。癒し18〜24／0.3、大きな癒し45〜55／0.6、深い癒し100〜120／1.0、命の光220〜260／1.4。最大HPまで回復し、フィールドも同じ計算。正本は [魔法設定](../web/src/data/skills.md)。

## 買い物と探索

防具屋に革の帽子・鉄の兜・魔導の三角帽子、武器屋に水晶の杖、道具屋に上位回復と300Gの永久強化アイテムを追加しました。力の果実は基礎攻撃+1、生命の果実は基礎HP+5。フィールドで使い、効果を保存します。

通常・巨大版の街に宿屋の主人を配置。15GでHP／MP全回復と毒治療、いいえと金不足では消費しません。近くの宝箱は店の基本装備から素材装備へ変更し、街の出口に方向案内を追加しました。

## 戦闘とクリア後

戦闘終了後6歩は遭遇抽選を止めます。通れない入力・会話は歩数に含めません。通常・巨大版の洞窟に、250EXP・100Gのはぐれクリスタルをweight5で追加。HP8・防御50、敵ターンに50%で逃走します。

魔王撃破後は玉座奥に裂け目が出現し、虚無の異空間へ入れます。帰還出口もあります。最奥の古代の虚無神はHP1200・攻撃55・防御25・魔力55で、1ターン2回行動。虚無の爪痕・魔法攻撃の虚無の波動・60回復の深淵の闇を使います。1人パーティーのため波動は主人公への攻撃です。倒すと一度だけ「虚無の覇者」と星屑のオーブを取得。オーブは装飾品でHP+100・MP+50・攻撃+30・防御+30・魔力+30です。

小型版の正本・バイナリ・起動URLは変更しません。宿屋とレア敵は通常・巨大版のみ、成長・魔法・自動保存・クリア後の異空間は共通エンジンの変更です。

## 検証

`npm --prefix web run typecheck` と `npm --prefix web run verify:all`。追加の `verify:gameplay` で保存と再開・世界間引き継ぎ・初期化・破損や容量エラー・報酬の二重付与防止・6歩保護・敵逃走・成長全快・強化・宿泊・3世界のポータル到達と裏ボスを検証します。

UIの検証は既存のDOMテストを使います。今回の改修の実ブラウザとスマホ実機での目視・操作確認は未実施です。Git操作・デプロイは行っていません。

最終実行結果：型チェック・全Web検証・Python18テスト・17従来バイナリ往復・65容量／形式往復・フォント検証・製品ビルドが成功しました。3デモと敵PNGを再生成し、追加敵と虚無の異空間のPNGを目視確認しています。小型版binと正本JSONのSHA-256は変更前と一致しています。

追加のverify:magicは物理と魔法の独立性・戦闘とフィールドの回復一致・成長／装備／上限・旧configと旧セーブ・世界間引き継ぎ・入力検証を確認します。

## 第2部の拡充

虚無の回廊には紫の戦闘背景を使う通常敵3体（HP160・220・300、EXP120・160・200）を追加し、6%の確率で出現します。上位技・回復・装備を整えて挑む育成用のエリアです。はぐれクリスタルは既存のID10とstray-crystal.jsonを維持し、同名の敵を重複登録しません。

裏ボスの2回行動は敵ターンのログにまとめて表示します。防御は両攻撃に効き、死んだ後に2回目の行動はしません。毒の追加ダメージはターンに1回。敵の魔法攻撃は魔力を使い、物理防御を引かず、防御コマンドで軽減します。

真のクリアの証は各世界のクリア＋虚無神撃破フラグから読み、既存セーブへ保存します。プレイ画面はTRUE CLEAR、紹介／タイトルは「★ TRUE CLEAR — 世界の真の覇者」と表示し、別世界へ主人公を連れて行ってもタイトルの証は保持します。セーブ初期化で全世界の進行と証を消します。

独立した魔力の式はユーザーの確認に従い維持しています。帽子は今回指定の防御+3へ変更し、魔力+6も保持します。宿屋の確認文と「名前変更」のボタン名を今回指定へ更新しました。


## 保存の修復と別画面の更新

保存のキーは従来の `tagquest.play-save.v1` を維持します。直前の正常な保存は `.backup`、修復前の読み込めなかった原本は `.recovery` を末尾に付けたキーへ保存します。退避できない場合は原本を上書きせず、保存失敗を通知します。「はじめから」の確認付き初期化ではバックアップと退避分も消します。

別タブなどで保存内容が更新されると、古い画面の移動・買い物・装備変更・初期化・保存を止めます。画面の案内と「再読み込みして続ける」から最新の主人公・世界を読み直してください。別の世界を開く場合も、同じ主人公の保存を使うため同じ扱いです。実機の同時操作は未検証で、コードとDOM検証では保存更新後の停止と再読み込み導線を確認しています。

# 地図と7施設の拡張

通常版16マップ・5,515マス、巨大版28マップ・14,230マス。街の東の通りから「旅人の港と商人街」へ入り、施設・地下水路・沈没神殿・合鍵で入る地下蔵を探索できます。

小型版の正本JSONと `art/adventure-small/` の全11ファイルは変更していません。302Bバイナリ／439B URL／444B NDEF、予約5B込み449B／496B・残り47B。`web/scripts/small-world-lock.json` に変更前のSHA-256を記録し、`verify:demos` と `verify:ultimate` でファイル一覧とバイト列を検証します。この改修では小型版を再出力していません。

## 地図

メニューの「ちず」で現在の大陸と訪問済み拠点を見られます。赤いピンが現在地、番号と地名が拠点です。屋内ではその地域へ入る入口を示し、上部に実際のステージ名と座標を表示します。「現在のマップ」を選ぶと、足元中心の正確な座標へピンを置きます。訪問済みの別大陸を選べ、ネストや港などの屋内拠点も大陸上の地域入口と結び付けます。北・東の案内とマス単位の方角の目安を表示します。移動距離は道のりそのものではありません。点滅はCSSで行い、動きを減らす設定では停止します。

施設のない小型版では、今回の地図・施設への導線・仲間コマンドを表示しません。施設は配置のある世界だけで有効になります。

## 施設の使い方

|施設|操作と仕様|
|---|---|
|鍛冶屋|素材17・18とGで所持装備を＋1・＋2へ。同じ種類の全コピーへ適用。武器は段階ごとに攻撃+3、防具は防御+2。＋1は岩のかけら2個＋100G、＋2は岩3個・水晶2個＋250G。装備本体を消費せず、自動で持ち替えません。|
|旅の祠|訪問済みの別マップのみ、前回の位置へ無料で移動。到着後6歩は遭遇保護。訪問歴は世界別。|
|遊技場|1G＝1コイン。レースは4匹の1着予想、10コイン・当たり30コイン。全着順を表示。ハイ＆ローは1〜9、5コイン・当たり7コイン、同数は外れ。閉じる／再読み込み時は未決の賭けを放棄。景品は500コインのメタル砕きの剣、300の幸運の指輪、80の経験値の書、800の祝福の靴、600の天恵のブローチ、1000の黄金の指輪。|
|地下水路・闇市|港の古井戸から確認後に下ります。元の街の井戸も、置かれたアイテムを回収して再調査すると利用できます。合鍵500Gで鉄格子が開き、港の古い民家の地下蔵へ入れます。地上への出口は港の井戸付近です。|
|占いの館|現在の物語目標と、未討伐の主の生息地・推奨Lvを表示します。|
|港と帆船|船長への確認で沈没神殿へ無料渡航。神殿の船長から港へ戻れます。宝箱と鉄格子、洞窟系の敵を配置。|
|魔物牧場|通常の魔物の勝利時に5%で加入の提案。受け入れる／見送るを選べます。未加入の対象だけ抽選し、ボス・NPC戦・逃走では発生しません。仲間から1匹を選ぶと戦闘の「まもの」で1戦1回、援護攻撃またはHP回復。HP全快の回復は消費せず、使用後はコマンドを無効化します。|

ID39「メタル砕きの剣」は攻撃+18・メタルへの物理攻撃で防御を無視。40「幸運の指輪」は防御+2・会心率+15%、会心は物理威力2倍。41「経験値の書」は500EXP（上限まで）、レベルアップで全回復と習得ログ。42「盗賊の合鍵」は使用では減りません。

鍛冶の強化値・コイン・仲間と編成は主人公と共通保存し、別世界へ引き継ぎます。訪問位置・宝箱・開いた鉄格子・撃破・賞金報告は世界別です。古いセーブで新項目がない場合は未強化・コイン0・仲間なしとして読みます。小型版では施設由来の強化・会心・メタル特効・魔物支援を適用しません。

主のID15〜17、能力・報酬・一度きりの撃破と消失、ギルド報告の追加賞金・称号は前回の仕様を維持します。白銀の牙剣の凍結は15%で次の敵ターンを止める効果です。

## 編集と出力

- 固定マップ・接続：`web/src/editor/facility-presets.ts`。通常・巨大版だけ `adventure-presets.ts` から呼びます。
- 料金・配当・景品・強化レシピ・仲間候補：`web/src/data/facility-config.json`。
- 建物・船・鉄格子のピクセル：`web/src/data/objects/ultimate-facilities.ts`。
- 地図の配置・描画：`web/src/renderer/world-map.ts`。
- メニュー：`web/src/game/facility-menu.ts`。
- 新しいアイテム・装備効果：`web/src/data/item-catalog.json`。

`npm --prefix web run export:expanded` は通常・巨大版だけを再生成します。JSON・bin・URL・レポート・PNGを同期し、小型版に触れません。通常版1,463B／URL1,987B／NDEF1,992B、巨大版3,082B／URL4,146B／NDEF4,151B。既存の共有URLには変更が反映されないため、新しく出力したURLで遊びます。

`typecheck` と `verify:all` が成功。Web全検証、Python18テスト・17旧形式往復・追加の容量／形式検証・フォント検証・製品ビルドが通っています。追加検証には地図の正確なピン・訪問履歴・ネスト表示、施設のDOM／キーボード操作、強化・配当・カード・鍵・船の往復・魔物加入5%の境界・保存／別世界引き継ぎ・支援1回・小型全ファイル保持を含みます。PNGで施設街と神殿を目視確認しました。実ブラウザ・スマホ実機の確認は未実施。Git・push・デプロイは行っていません。
